# 광전식 감지기 수증기 오작동 판별 실험 — 최종 데이터 분석 리포트
## 수증기량 "소(小)" / "중(中)" / "대(大)" 통합 비교, 각 1~10회차 (총 30개 데이터셋)

---

## 1. 실험 개요

- **목적**: 쿠킹 클래스(조리) 환경 수증기를 화재 연기로 오인해 자동화재탐지설비(자탐)가 오작동하지 않는지, 수증기량(세기)에 따라 반응이 어떻게 달라지는지 검증
- **측정 항목**: 루프저항(ohm), MQ2raw, 온도(C), 습도(%)
- **표본**: 소 10회차 + 중 10회차 + 대 10회차 = 총 30개 데이터셋(설계된 전체 표본 완료)
- ⚠️ "대" 구간은 로그 형식이 소/중과 다름(타임스탬프 `12:45:49.360 ->` 포함, 초 단위 간격 5초). 파싱 시 타임스탬프는 제외하고 동일한 측정값 4항목만 추출함.

### 2-1. "대" 구간에서 새로 확인된 이상치 패턴
- **1회차**: 다른 회차 대비 측정 시간이 2~3배 김(약 4분, 50샘플). 습도가 88.4%까지 상승해 다른 회차 peak(78~83%)보다 훨씬 높음 → **측정 시간(노출 시간) 자체가 다른 회차와 다르므로 직접 비교 시 유의 필요**. 세기(대) 자체의 특성이라기보다 실험 프로토콜 차이로 추정됨.
- **2, 3회차**: 습도가 아직 거의 변하지 않은 초반 구간(baseline으로 잡은 처음 3개 샘플 포함)에서 이미 MQ2raw가 10500~11800대까지 급격히 상승 중 → 소 1회차와 유사한 **센서 워밍업(예열) 아티팩트**로 판단됨. 이 두 회차는 MQ2 변화율이 각각 9.06%, 7.81%로 다른 회차(0.1~1.0%)와 확연히 다름.
- → **소 1회차 + 대 2,3회차 = 총 3개 회차가 워밍업 아티팩트로 재확인됨**. 워밍업은 세기와 무관하게 산발적으로 발생하는 실험 초기 현상으로 판단되며, AI 학습 데이터에서 별도 플래그 처리를 권장.

## 3. 소 vs 중 vs 대 — 3구간 통합 비교

| 구분 | 사용 회차(n) | 습도 baseline(%) | 습도 peak(%) | **습도 상승폭(%p)** | MQ2 변화율(%) | 루프저항 변동폭(ohm) |
|---|---|---|---|---|---|---|
| **소** | 2~10회차(9) | 56.9 (54.3~58.6) | 67.5 (63.3~70.8) | **10.7 (7.8~15.1)** | 0.35 (0.15~0.63) | 0.49 (0.3~1.0) |
| **중** | 1~10회차(10) | 55.8 (52.9~57.9) | 75.6 (71.9~77.9) | **19.8 (17.5~23.3)** | 0.32 (0.17~0.48) | 0.46 (0.3~0.9) |
| **대** | 4~10회차(7) | 55.0 (53.3~56.4) | 80.0 (78.0~80.8) | **25.0 (24.2~27.0)** | 0.53 (0.27~1.01) | 0.69 (0.3~1.8) |

(제외된 이상치: 소 1회차, 대 1·2·3회차 — 2절 참고)

### 핵심 발견

1. **습도 상승폭이 수증기량 세기에 명확한 단조 증가(dose-response) 관계를 보임**
   - 소(10.7%p) → 중(19.8%p) → 대(25.0%p)로 세기가 커질수록 상승폭도 커지되, **증가폭은 체감**(소→중 +9.1%p, 중→대 +5.2%p). 즉 로그형/포화형 곡선에 가까운 관계로 보임.
   - 3구간의 습도 상승폭 분포가 서로 거의 겹치지 않음: 소(7.8~15.1) / 중(17.5~23.3) / 대(24.2~27.0). **경계값 후보**: 소/중 경계 약 16~17%p, 중/대 경계 약 23~24%p.
   - 습도 peak 절대값도 소(63~71%) / 중(72~78%) / 대(78~81%)로 잘 분리됨. 다만 대 1회차처럼 노출 시간이 길어지면 peak가 88%까지 갈 수 있어, **절대 peak값보다 baseline 대비 상승폭 지표가 더 안정적**임을 재확인.

2. **MQ2raw·루프저항은 세기와 무관하게 계속 낮은 반응성 유지 (워밍업 이상치 제외 시)**
   - 클린 데이터 기준 MQ2 변화율: 소 0.35% → 중 0.32% → 대 0.53%로 큰 차이 없이 1% 미만 유지.
   - 루프저항 변동폭도 소 0.49 → 중 0.46 → 대 0.69ohm으로 여전히 미미함.
   - → **결론(재확인)**: MQ2raw·루프저항은 "화재 vs 수증기" 판별에는 유효(둔감함 자체가 특징)하지만, "수증기 세기" 구분에는 기여하지 않음. 세기 판별은 **습도 채널이 전담**.

3. **워밍업 아티팩트는 세기와 무관하게 산발적으로 발생**
   - 소 1회차, 대 2·3회차에서 공통적으로 "측정 시작 직후 MQ2raw가 습도 변화와 무관하게 급상승"하는 패턴 확인.
   - → AI 학습 파이프라인에서는 **회차별 baseline 구간(첫 3~5샘플)의 MQ2 변화율 자체를 이상치 감지 필터로 사용**하는 것을 제안(예: baseline 구간 내 MQ2 변화율이 3% 이상이면 워밍업 의심으로 플래그).

## 4. 잠정 판별 로직 제안 (AI 담당자 검토용)

```
습도_상승폭 = 습도_peak - 습도_baseline (baseline = 첫 3개 샘플 평균)

if 습도_상승폭 < 16%p:        → 수증기-소 추정
elif 습도_상승폭 < 23~24%p:   → 수증기-중 추정
else:                          → 수증기-대 추정

(공통 전제) MQ2raw 변화율이 baseline 대비 큰 폭(수%~수십%)으로 습도 변화와 무관하게 급변하는 경우
→ 화재 반응이거나 센서 워밍업 아티팩트일 가능성 → 별도 검증 필요
```
- 경계값(16%p, 23~24%p)은 표본 10개씩 기준의 잠정치이며, 실제 서비스 적용 전 표본 확대 및 화재 대조군과의 교차검증이 필요함.
- "화재 vs 수증기" 1차 판별은 기존에 확인된 "화재 시 습도 하강(~45%)" 원리를 사용하고, 수증기로 판별된 이후 2차로 세기(소/중/대)를 위 로직으로 분류하는 2단계 구조를 제안.

## 5. AI 담당자 전달 시 참고 사항

1. **파일**: `vapor_raw_data_{소|중|대}.csv`, `vapor_summary_{소|중|대}.csv` — 6개 파일 모두 동일 스키마로 그대로 concat 가능.
2. **레이블링**: `수증기량_구분` 컬럼(소/중/대) 그대로 다중 클래스 라벨로 사용 가능. 전부 "화재 아님(negative)" 클래스의 하위 구분.
3. **이상치 처리 필요 회차**: 소-1회차(워밍업 의심), 대-1회차(노출시간 상이, 프로토콜 차이), 대-2·3회차(워밍업 의심) — 학습 시 제외 또는 별도 플래그 권장.
4. **핵심 피처(최종)**:
   - 습도 baseline 대비 상승폭(%p) — 세기(소/중/대) 분류 1순위 피처
   - 습도 상승 기울기(slope)
   - MQ2raw baseline 대비 변화율(%) — 화재 vs 수증기 판별용, 세기 분류에는 비권장
   - 루프저항 변동폭 — 자탐 판정 로직 교차검증용
   - (신규 제안) baseline 구간 내 MQ2 자체 변화율 — 워밍업 이상치 탐지용
5. **다음 단계**: 실제 화재(연소) 데이터와의 대조 분석(습도 하강 패턴 정량 검증)이 남은 핵심 과제. 수증기 소/중/대 실험은 이번 리포트로 데이터 수집·1차 분석 완료.
