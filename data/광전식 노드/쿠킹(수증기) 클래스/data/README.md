# data/ 폴더 구조 안내

이 폴더는 각 서브시스템(엣지 노드)별 실험 데이터를 아래 규칙으로 정리합니다.

```
data/
└── {서브시스템}_노드/
    └── {실험명}/
        ├── raw/        # 원시 시계열 데이터
        ├── summary/    # 회차별 요약 통계
        ├── analysis/   # 분석 리포트(.md)
        └── README.md   # 해당 실험 설명
```

|---|---|

## ⚠️ 폴더가 GitHub에 안 보이거나 인식이 안 될 때

**Git은 폴더 자체를 추적하지 않고, 파일만 추적합니다.** 즉 파일이 하나도 없는 빈 폴더를 로컬에서 아무리 여러 단계로 만들어도, `git add`/`commit`/`push` 시 커밋할 대상이 없어서 GitHub에는 아예 올라가지 않습니다(로컬 탐색기에서는 보이는데 GitHub 웹에서는 안 보이는 게 이 증상입니다).

**해결 방법**: 폴더를 만들 때 반드시 그 폴더 안에 파일(CSV, README.md 등)을 최소 1개 이상 넣은 상태로 커밋하세요. 예를 들어 아직 데이터가 없는 실험 폴더를 미리 만들어두고 싶다면, 빈 폴더 대신 `README.md` 하나만이라도 넣어서 커밋하면 GitHub에 폴더가 정상적으로 나타납니다.

```bash
# 예시: 새 실험 폴더를 미리 만들어두고 싶을 때
mkdir -p data/가스계_노드/중량_감지_실험
echo "# 가스계 중량 감지 실험 (준비 중)" > data/가스계_노드/중량_감지_실험/README.md
git add data/가스계_노드/중량_감지_실험/README.md
git commit -m "가스계 중량 감지 실험 폴더 추가"
git push
```

## 폴더/파일명 규칙

- 공백 대신 언더스코어(`_`) 사용 권장 (URL, 명령줄에서 다루기 편함)
- 괄호 `()` 는 GitHub 자체에서는 문제 없지만, 터미널·스크립트에서 이스케이프가 번거로우므로 가능하면 지양 (예: `쿠킹(수증기)` → `쿠킹_수증기`)
- 회차별 원시 데이터는 `raw/`, 가공된 요약 통계는 `summary/`, 분석 리포트는 `analysis/`로 항상 3분할
