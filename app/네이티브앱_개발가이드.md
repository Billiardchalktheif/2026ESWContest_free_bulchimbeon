# 네이티브 앱 개발 가이드 (안드로이드, 우리 시스템 기준)

> 설치 방법(`처음부터_시작하기_Windows.md`)이나 고급기능(`네이티브앱_고급기능_가이드.md`)은 따로 있으니, 이 문서는 **"우리 프로젝트 기준으로 뭘, 어떤 순서로 만들어야 하는지"**만 정리했습니다. 순서대로 진행하면 됩니다.

---

## 0. 목표

라즈베리파이 서버(`/api/...`)에 물어봐서, 5개 설비 상태를 폰으로 확인하고 알림 받는 앱을 만듭니다. **네이티브 앱만의 강점 기능(QR코드, PDF리포트, 원격트리거)**까지 넣는 게 목표입니다.

---

## 1. 오늘 할 것 — 폰·개발환경 준비 (약 15분)

- [ ] 안드로이드 폰: 설정 → 휴대전화 정보 → 소프트웨어 정보 → "빌드번호" 7번 탭 (개발자 모드 활성화)
- [ ] 설정 → 개발자 옵션 → **USB 디버깅** 켜기
- [ ] USB 케이블로 컴퓨터 연결, 폰 화면에 뜨는 "USB 디버깅 허용" 팝업 승인
- [ ] 터미널에서 확인:
  ```
  flutter devices
  ```
  폰 기종이 목록에 뜨면 성공

---

## 2. Flutter 프로젝트 생성

```
flutter create bulchimbeon_app
cd bulchimbeon_app
flutter run
```
기본 카운터 앱이 폰에 설치되면 환경설정 완료입니다.

---

## 3. 화면 구성 계획 (총 4개 화면)

많이 안 만들어도 됩니다. 핵심 4개만:

| 화면 | 역할 |
|---|---|
| **홈(Home)** | 5개 설비 상태 요약 카드 (정상/주의/경보 색상) |
| **알림 목록(Alerts)** | 경보 이력, 확인(Acknowledge) 버튼 |
| **QR 스캔(Scanner)** | 소화기/유도등 QR 찍으면 해당 설비 상세정보 |
| **설정(Settings)** | 서버 IP 주소 입력, 알림 on/off |

## 4. 서버 API 연동 리스트 (이미 정의된 엔드포인트)

서버 담당 친구가 이미 준비해둔 API입니다 — 앱은 이걸 호출하기만 하면 됩니다.

```
GET /api/status
→ 전체 모듈 현재 상태 (홈 화면 카드용)
   응답 예시: {"자탐1": "normal", "수계": "warning", ...}

GET /api/history/{module}
→ 특정 모듈 시계열 데이터 (그래프용, 상세화면에서 사용)

GET /api/events
→ 최근 경보 이력 (알림 목록 화면용)

POST /api/alert/ack
→ 경보 확인 처리 (알림 목록에서 "확인" 버튼 누를 때)
```

**Flutter에서 API 호출하는 기본 패턴**:
```dart
import 'package:http/http.dart' as http;
import 'dart:convert';

Future<Map<String, dynamic>> fetchStatus() async {
  final response = await http.get(Uri.parse('http://라즈베리파이IP:포트/api/status'));
  return jsonDecode(response.body);
}
```

## 5. 만드는 순서 (우선순위대로)

### 5-1. 홈 화면 — 상태 조회 (가장 먼저)
- [ ] `/api/status` 호출해서 5개 설비 카드 표시
- [ ] 정상(초록)/주의(노랑)/경보(빨강) 색상 구분
- [ ] 새로고침 버튼 또는 자동 갱신(예: 10초마다)

### 5-2. 알림 목록 화면
- [ ] `/api/events` 호출해서 리스트로 표시
- [ ] 각 항목에 "확인" 버튼 → `/api/alert/ack` 호출

### 5-3. 푸시 알림 (경보 오면 폰 알림 뜨게)
- [ ] Firebase Cloud Messaging(FCM) 설정 — 이건 서버 쪽에서도 연동 코드가 필요해서 서버 담당자와 협업 필요
- [ ] 안드로이드 알림 권한 설정 (`AndroidManifest.xml`에 권한 추가)

### 5-4. QR코드 스캔 기능
- [ ] `qr_code_scanner` 또는 `mobile_scanner` 패키지 설치
  ```
  flutter pub add mobile_scanner
  ```
- [ ] 카메라 권한 설정 (`AndroidManifest.xml`)
- [ ] QR 스캔 → 소화기/유도등 ID 추출 → `/api/history/{module}` 호출해서 상세정보 표시

### 5-5. PDF 리포트 생성
- [ ] `pdf` 패키지 설치
  ```
  flutter pub add pdf printing
  ```
- [ ] "최근 30일 점검이력" 버튼 → `/api/history/{module}` 데이터를 PDF로 변환 → 저장/공유

### 5-6. (여유 되면) 원격 성능시험 트리거
- [ ] 서버에 트리거용 엔드포인트가 있는지 서버 담당자와 확인 (`POST /api/test/trigger` 같은 것 — 아직 없으면 추가 요청 필요)
- [ ] 버튼 하나로 이 API 호출

```xml
<uses-permission android:name="android.permission.POST_NOTIFICATIONS" />
```

## 7. 서버 IP 관련 주의사항

라즈베리파이랑 폰이 **같은 WiFi**에 연결돼 있어야 통신됩니다. 서버 IP 주소는:
- 라즈베리파이에서 `hostname -I` 또는 서버 실행 로그에서 확인
- 설정 화면에 직접 입력하게 만들어두면, IP가 바뀌어도 앱 재설치 없이 대응 가능 (권장)

## 8. 오늘부터 시작할 수 있는 것 (부품 없어도 됨)

| 순서 | 작업 | 부품 필요? |
|---|---|---|
| 1 | 폰 세팅, 프로젝트 생성 | ❌ |
| 2 | 화면 UI 레이아웃(디자인)만 먼저 만들기 | ❌ |
| 3 | API 연동 (서버 MOCK_MODE로 테스트) | 라즈베리파이는 필요, 노트북으로 대체 가능 |
| 4 | QR/PDF 기능 | ❌ (가짜 데이터로 테스트 가능) |
| 5 | 실제 라즈베리파이 서버와 최종 연동 | ✅ 실물 필요 |

**즉 5단계 빼고는 전부 지금 당장 진행 가능**합니다.
