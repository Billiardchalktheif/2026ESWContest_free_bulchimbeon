# 라즈베리파이 및 QR코드 연동 개발 마일스톤

> Flutter 애플리케이션과 라즈베리파이 서버 간의 원활한 연동 및 QR 스캐너 기능 구현을 위한 단계별 작업 계획서입니다.

## 1. 개발 진행 순서

### 📌 1단계: 통신 기반 검증
* **작업 내용**: 라즈베리파이 연동 가이드 STEP 0 ~ 5
* **목표**: 홈 화면에서 서버 실데이터 표출 확인
* **의의**: 네트워크 상태 및 `AndroidManifest.xml` 설정 등 클라이언트-서버 간 기본 통신이 정상적으로 이루어지는지 검증하는 가장 핵심적인 첫 단추입니다.

### 📌 2단계: 스캐너-서버 API 페어링
* **작업 내용**: 라즈베리파이 연동 가이드 STEP 6 (`scanner_screen.dart` 수정) + QR코드 생성 가이드 STEP 6 (`api.py`에 `equipment_db` 및 라우트 추가)
* **목표**: 앱의 스캔 결과와 서버의 조회 응답 구조 짝맞추기
* **의의**: 앱 클라이언트와 라즈베리파이 서버 간의 인터페이스 규격을 일치시키는 동시 작업 단계입니다.

### 📌 3단계: QR코드 이미지 생성 (독립 모듈)
* **작업 내용**: QR코드 생성 가이드 STEP 1 ~ 4
* **목표**: 파이썬 스크립트를 통한 실물 QR코드(`EXT-01` 등 짧은 식별자 포함) 이미지 생성
* **의의**: 서버 API 통신 구현과 독립적이므로 2단계와 병행하거나 일정 중 언제든지 유연하게 진행 가능한 작업입니다.

### 📌 4단계: 스캔 로직 단독 디버깅
* **작업 내용**: QR코드 생성 가이드 STEP 7
* **목표**: 실제 스캔 테스트를 통한 전체 로직 검증
* **의의**: 앱↔서버 통신이 확보된 상태에서 "QR 스캔과 결과 표시" 기능만 격리하여 테스트함으로써 디버깅 효율을 극대화합니다.

### 📌 5단계: 설정 화면 고도화
* **작업 내용**: 라즈베리파이 연동 가이드 STEP 7
* **목표**: 설정 화면 내 IP 저장 기능 구현
* **의의**: 개발 순서상 유연하게 배치 가능하며, 앱 재시작 시에도 IP가 유지되도록 하여 향후 지속적인 테스트 편의성을 확보합니다.

---

## 2. 핵심 체크포인트 및 트러블슈팅

작업 진행 중 문제가 발생할 경우 아래 항목들을 우선적으로 점검합니다.

* **네트워크 환경 및 방화벽**: 
  * 라즈베리파이와 스마트폰이 **동일한 Wi-Fi(로컬) 네트워크**에 연결되어 있는지 확인합니다.
  * 라즈베리파이 방화벽(ufw)에서 **5001번 포트**가 개방되어 있는지, `api.py`가 0.0.0.0으로 바인딩되었는지 점검합니다.
* **타임아웃 및 무한 로딩 방지**: 
  * 앱 내 HTTP 요청 시 `.timeout()` 설정이 정상 작동하는지 확인하여, 서버 무응답 시 로딩 스피너가 무한히 도는 현상을 방지합니다.
* **데이터 일치성 오류**:
  * QR코드에 들어있는 짧은 식별자(예: `EXT-01`)와 서버 `equipment_db`에 등록된 키(Key) 값의 대소문자 및 기호가 정확히 일치하는지 확인합니다.
