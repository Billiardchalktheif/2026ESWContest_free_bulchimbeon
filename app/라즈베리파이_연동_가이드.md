# 라즈베리파이 연동 가이드 — 순서대로 하나씩

> Flutter 앱(불침번)을 라즈베리파이 서버(api.py, 포트 5001)와 연동하는 작업 순서. 한 단계씩 끝내고 실행 확인 후 다음 단계로 넘어갈 것.

---

## STEP 0. 시작 전 준비 (코드 건드리기 전)

### 라즈베리파이에서 확인
- [ ] `api.py` 마지막 줄 확인 → `app.run(host='0.0.0.0', port=5001)` 인지 확인 (아니면 수정)
  - `host='127.0.0.1'`(기본값)이면 라즈베리파이 자기 자신에서만 접근 가능하고 폰에서는 절대 접속 불가
- [ ] `hostname -I` 로 IP 확인해두기 (예: `192.168.0.10`)
- [ ] 방화벽(ufw) 사용 중이면 포트 열기: `sudo ufw allow 5001`

### 폰에서 확인
- [ ] 폰 웹브라우저 열어서 `http://<라즈베리파이IP>:5001/api/status` 직접 접속
- → JSON이 뜨면 통과, 안 뜨면 Flutter 건드리기 전에 네트워크 문제부터 해결

## STEP 1. AndroidManifest.xml — 한 줄 추가

**파일**: `android/app/src/main/AndroidManifest.xml`

```xml
<application
    android:label="불침번"
    android:usesCleartextTraffic="true">   ← 이 줄 추가
```

이거 없으면 http 요청 자체가 막힘 (Android 9 이상 기본적으로 HTTPS만 허용)

## STEP 3. 새 파일 하나 추가 — `lib/api_config.dart`

IP 주소를 저장/불러오는 공용 헬퍼. **새로 만드는 파일**이라 기존 코드는 안 건드림.

```dart
import 'package:shared_preferences/shared_preferences.dart';

class ApiConfig {
  static Future<String> getServerIp() async {
    final prefs = await SharedPreferences.getInstance();
    return prefs.getString('server_ip') ?? '192.168.0.10';
  }

  static Future<void> setServerIp(String ip) async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.setString('server_ip', ip);
  }
}
```

## STEP 4. `home_screen.dart` — 통째로 교체

| 뺄 것 | 넣을 것 |
|---|---|
| `class HomeScreen extends StatelessWidget` | `class HomeScreen extends StatefulWidget` (+ State 클래스) |
| `final List<...> _modules = const [...]` (하드코딩 가짜데이터) | `List<...> _modules = []` (빈 리스트로 시작, API로 채움) |
| 없음 | `initState()` 안에서 `_fetchStatus()` 호출 |
| 없음 | `_fetchStatus()` 함수 — http.get + timeout + try/catch |
| `build()`이 바로 리스트를 그림 | `build()`이 로딩중/에러/정상 3갈래로 분기 |

### 전체 코드

```dart
import 'package:flutter/material.dart';
import 'package:http/http.dart' as http;
import 'dart:convert';
import 'api_config.dart';

class HomeScreen extends StatefulWidget {
  const HomeScreen({super.key});

  @override
  State<HomeScreen> createState() => _HomeScreenState();
}

class _HomeScreenState extends State<HomeScreen> {
  List<Map<String, dynamic>> _modules = [];
  bool _loading = true;
  String? _error;

  @override
  void initState() {
    super.initState();
    _fetchStatus();
  }

  Future<void> _fetchStatus() async {
    setState(() {
      _loading = true;
      _error = null;
    });
    try {
      final ip = await ApiConfig.getServerIp();
      final response = await http
          .get(Uri.parse('http://$ip:5001/api/status'))
          .timeout(const Duration(seconds: 5));

      if (response.statusCode == 200) {
        final data = jsonDecode(response.body) as List;
        setState(() {
          _modules = data.cast<Map<String, dynamic>>();
          _loading = false;
        });
      } else {
        setState(() {
          _error = '서버 응답 오류 (${response.statusCode})';
          _loading = false;
        });
      }
    } catch (e) {
      setState(() {
        _error = '서버 연결 실패: 라즈베리파이 IP와 전원을 확인하세요';
        _loading = false;
      });
    }
  }

  Color _statusColor(String status) {
    switch (status) {
      case 'normal':
        return Colors.green;
      case 'warning':
        return Colors.orange;
      case 'critical':
        return Colors.red;
      default:
        return Colors.grey;
    }
  }

  String _statusLabel(String status) {
    switch (status) {
      case 'normal':
        return '정상';
      case 'warning':
        return '주의';
      case 'critical':
        return '경보';
      default:
        return '알 수 없음';
    }
  }

  @override
  Widget build(BuildContext context) {
    if (_loading) {
      return const Center(child: CircularProgressIndicator());
    }
    if (_error != null) {
      return Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Text(_error!, textAlign: TextAlign.center),
            const SizedBox(height: 12),
            ElevatedButton(onPressed: _fetchStatus, child: const Text('다시 시도')),
          ],
        ),
      );
    }
    return RefreshIndicator(
      onRefresh: _fetchStatus,
      child: ListView.builder(
        padding: const EdgeInsets.all(12),
        itemCount: _modules.length,
        itemBuilder: (context, index) {
          final module = _modules[index];
          final status = module['status'] as String;
          return Card(
            margin: const EdgeInsets.symmetric(vertical: 6),
            child: ListTile(
              leading: CircleAvatar(
                backgroundColor: _statusColor(status),
                child: const Icon(Icons.circle, color: Colors.transparent),
              ),
              title: Text(module['name'] as String),
              trailing: Text(
                _statusLabel(status),
                style: TextStyle(
                  color: _statusColor(status),
                  fontWeight: FontWeight.bold,
                ),
              ),
            ),
          );
        },
      ),
    );
  }
}
```

## STEP 5. `alerts_screen.dart` — 같은 패턴 반복

STEP 4랑 완전히 똑같은 구조로 바꾸되:
- `/api/status` → `/api/events` 로만 바꿔서 적용
- `_modules` → `_alerts`, 필드명(`module`, `message`, `time`)에 맞춰 UI 조정

### 전체 코드

```dart
import 'package:flutter/material.dart';
import 'package:http/http.dart' as http;
import 'dart:convert';
import 'api_config.dart';

class AlertsScreen extends StatefulWidget {
  const AlertsScreen({super.key});

  @override
  State<AlertsScreen> createState() => _AlertsScreenState();
}

class _AlertsScreenState extends State<AlertsScreen> {
  List<Map<String, dynamic>> _alerts = [];
  bool _loading = true;
  String? _error;

  @override
  void initState() {
    super.initState();
    _fetchEvents();
  }

  Future<void> _fetchEvents() async {
    setState(() {
      _loading = true;
      _error = null;
    });
    try {
      final ip = await ApiConfig.getServerIp();
      final response = await http
          .get(Uri.parse('http://$ip:5001/api/events'))
          .timeout(const Duration(seconds: 5));

      if (response.statusCode == 200) {
        final data = jsonDecode(response.body) as List;
        setState(() {
          _alerts = data.cast<Map<String, dynamic>>();
          _loading = false;
        });
      } else {
        setState(() {
          _error = '서버 응답 오류 (${response.statusCode})';
          _loading = false;
        });
      }
    } catch (e) {
      setState(() {
        _error = '서버 연결 실패: 라즈베리파이 IP와 전원을 확인하세요';

      });
    }
  }

  @override
  Widget build(BuildContext context) {
    if (_loading) {
      return const Center(child: CircularProgressIndicator());
    }
    if (_error != null) {
      return Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Text(_error!, textAlign: TextAlign.center),
            const SizedBox(height: 12),
            ElevatedButton(onPressed: _fetchEvents, child: const Text('다시 시도')),
          ],
        ),
      );
    }
    if (_alerts.isEmpty) {
      return RefreshIndicator(
        onRefresh: _fetchEvents,
        child: ListView(
          children: const [
            SizedBox(height: 200),
            Center(child: Text('현재 경보 없음')),
          ],
        ),
      );
    }
    return RefreshIndicator(
      onRefresh: _fetchEvents,
      child: ListView.builder(
        padding: const EdgeInsets.all(12),
        itemCount: _alerts.length,
        itemBuilder: (context, index) {
          final alert = _alerts[index];
          return Card(
            margin: const EdgeInsets.symmetric(vertical: 6),
            child: ListTile(
              leading: const Icon(Icons.warning_amber, color: Colors.orange),
              title: Text('${alert['module']} — ${alert['message']}'),
              subtitle: Text(alert['time'] as String),
              trailing: TextButton(
                onPressed: () {
                  // 나중에 /api/alert/ack 연동 예정
                  ScaffoldMessenger.of(context).showSnackBar(
                    const SnackBar(content: Text('확인 처리됨 (임시)')),
                  );
                },
                child: const Text('확인'),
              ),
            ),
          );
        },
      ),
    );
  }
}
```

## STEP 6. `scanner_screen.dart` — `onDetect` 함수 하나만 수정

**뺄 것**: `onDetect`에서 `setState(() { _scannedCode = ...; })`만 하고 끝나던 부분

**더할 것**: 스캔되자마자 서버에 물어보는 로직

```dart
import 'package:flutter/material.dart';
import 'package:mobile_scanner/mobile_scanner.dart';
import 'package:http/http.dart' as http;
import 'dart:convert';
import 'api_config.dart';

class ScannerScreen extends StatefulWidget {
  const ScannerScreen({super.key});

  @override
  State<ScannerScreen> createState() => _ScannerScreenState();
}

class _ScannerScreenState extends State<ScannerScreen> {
  String? _scannedCode;
  Map<String, dynamic>? _equipmentInfo;
  bool _loading = false;
  String? _error;

  Future<void> _fetchEquipmentInfo(String code) async {
    setState(() {
      _scannedCode = code;
      _loading = true;
      _error = null;
    });
    try {
      final ip = await ApiConfig.getServerIp();
      final response = await http
          .get(Uri.parse('http://$ip:5001/api/equipment/$code'))
          .timeout(const Duration(seconds: 5));

      if (response.statusCode == 200) {
        setState(() {
          _equipmentInfo = jsonDecode(response.body) as Map<String, dynamic>;
          _loading = false;
        });
      } else {
        setState(() {
          _error = '설비 정보를 찾을 수 없습니다 (${response.statusCode})';
          _loading = false;
        });
      }
    } catch (e) {
      setState(() {
        _error = '서버 연결 실패: 라즈베리파이 IP와 전원을 확인하세요';
        _loading = false;
      });
    }
  }

  void _reset() {
    setState(() {
      _scannedCode = null;
      _equipmentInfo = null;
      _error = null;
    });
  }

  @override
  Widget build(BuildContext context) {
    if (_scannedCode != null) {
      return Center(
        child: Padding(
          padding: const EdgeInsets.all(24),
          child: Column(
            mainAxisAlignment: MainAxisAlignment.center,
            children: [
              if (_loading) const CircularProgressIndicator(),
              if (!_loading && _error == null) ...[
                const Icon(Icons.check_circle, size: 60, color: Colors.green),
                const SizedBox(height: 16),
                Text('스캔된 코드: $_scannedCode', style: const TextStyle(fontSize: 18)),
                const SizedBox(height: 8),
                if (_equipmentInfo != null)
                  Text(_equipmentInfo.toString(), textAlign: TextAlign.center),
              ],
              if (!_loading && _error != null) ...[
                const Icon(Icons.error_outline, size: 60, color: Colors.red),
                const SizedBox(height: 16),
                Text(_error!, textAlign: TextAlign.center),
              ],
              const SizedBox(height: 24),
              ElevatedButton(
                onPressed: _reset,
                child: const Text('다시 스캔하기'),
              ),
            ],
          ),
        ),
      );
    }

    return MobileScanner(
      onDetect: (capture) {
        final List<Barcode> barcodes = capture.barcodes;
        if (barcodes.isNotEmpty && barcodes.first.rawValue != null) {
          _fetchEquipmentInfo(barcodes.first.rawValue!);
        }
      },
    );
  }
}
```

## STEP 7. `settings_screen.dart` — 저장 버튼 로직만 교체

**뺄 것**:
```dart
onPressed: () {
  ScaffoldMessenger.of(context).showSnackBar(
    SnackBar(content: Text('저장됨: ${_ipController.text}')),
  );
}
```

**넣을 것**:
```dart
onPressed: () async {
  await ApiConfig.setServerIp(_ipController.text);
  ScaffoldMessenger.of(context).showSnackBar(
    SnackBar(content: Text('저장됨: ${_ipController.text}')),
  );
}
```

그리고 `initState()`에서 저장된 IP를 불러와서 `_ipController.text`에 미리 채워넣기 (앱 재시작해도 값 유지되도록)

### 수정 반영된 전체 코드 (PDF 기능 포함)

```dart
import 'package:flutter/material.dart';
import 'package:pdf/pdf.dart';
import 'package:pdf/widgets.dart' as pw;
import 'package:printing/printing.dart';
import 'api_config.dart';

class SettingsScreen extends StatefulWidget {
  const SettingsScreen({super.key});

  @override
  State<SettingsScreen> createState() => _SettingsScreenState();
}

class _SettingsScreenState extends State<SettingsScreen> {
  final TextEditingController _ipController = TextEditingController();

  @override
  void initState() {
    super.initState();
    _loadSavedIp();
  }

  Future<void> _loadSavedIp() async {
    final ip = await ApiConfig.getServerIp();
    setState(() {
      _ipController.text = ip;
    });
  }

  // 나중에 /api/history 연동되면 이 가짜 데이터 대신 실제 결과가 들어감
  final List<Map<String, String>> _reportData = const [
    {'설비': '자탐1 (차동식)', '상태': '정상'},
    {'설비': '자탐2 (광전식)', '상태': '정상'},
    {'설비': '수계', '상태': '주의'},
    {'설비': '가스계', '상태': '정상'},
    {'설비': '소화기', '상태': '정상'},
    {'설비': '유도등', '상태': '경보'},
  ];

  Future<void> _generatePdf() async {
    final pdf = pw.Document();

    pdf.addPage(
      pw.Page(
        build: (context) {
          return pw.Column(
            crossAxisAlignment: pw.CrossAxisAlignment.start,
            children: [
              pw.Text('불침번 — 점검이력 리포트',
                  style: pw.TextStyle(fontSize: 20, fontWeight: pw.FontWeight.bold)),
              pw.SizedBox(height: 8),
              pw.Text('생성일: ${DateTime.now().toString().split('.')[0]}'),
              pw.SizedBox(height: 20),
              pw.Table.fromTextArray(
                headers: ['설비', '상태'],
                data: _reportData.map((row) => [row['설비']!, row['상태']!]).toList(),
              ),
            ],
          );
        },
      ),
    );

    await Printing.layoutPdf(
      onLayout: (PdfPageFormat format) async => pdf.save(),
    );
  }

  @override
  Widget build(BuildContext context) {
    return Padding(
      padding: const EdgeInsets.all(16),
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          const Text('서버 IP 주소', style: TextStyle(fontWeight: FontWeight.bold)),
          const SizedBox(height: 8),
          TextField(
            controller: _ipController,
            decoration: const InputDecoration(
              border: OutlineInputBorder(),
              hintText: '예: 192.168.0.10',
            ),
          ),
          const SizedBox(height: 16),
          ElevatedButton(
            onPressed: () async {
              await ApiConfig.setServerIp(_ipController.text);
              ScaffoldMessenger.of(context).showSnackBar(
                SnackBar(content: Text('저장됨: ${_ipController.text}')),
              );
            },
            child: const Text('저장'),
          ),
          const SizedBox(height: 32),
          const Divider(),
          const SizedBox(height: 16),
          const Text('점검이력 리포트', style: TextStyle(fontWeight: FontWeight.bold)),
          const SizedBox(height: 8),
          ElevatedButton.icon(
            onPressed: _generatePdf,
            icon: const Icon(Icons.picture_as_pdf),
            label: const Text('PDF 생성'),
          ),
        ],
      ),
    );
  }
}
```

## 한눈에 순서 요약

```
1. Manifest 한 줄 추가                  (android/app/.../AndroidManifest.xml)
2. 패키지 2개 설치                       (flutter pub add http / shared_preferences)
3. api_config.dart 새로 만들기           (lib/api_config.dart)
4. home_screen.dart 교체                (StatelessWidget → StatefulWidget)
5. alerts_screen.dart 교체              (4번과 동일 패턴)
6. scanner_screen.dart — onDetect 수정  (스캔 즉시 서버 조회)
7. settings_screen.dart — 저장 버튼 연결 (실제 저장 + 재시작 시 유지)
```

**진행 원칙**: 한 번에 다 바꾸지 말고, 한 단계 끝날 때마다 실제 폰에서 실행해서 확인 후 다음 단계로 넘어갈 것. 4번(홈 화면) 끝내고 데이터가 뜨는지 확인한 다음 5번으로 진행하는 식.

## 트러블슈팅 체크리스트

문제가 생기면 이 순서로 확인:

- [ ] 라즈베리파이가 켜져 있고 `api.py`가 실행 중인가?
- [ ] 폰과 라즈베리파이가 **같은 와이파이**에 연결되어 있는가?
- [ ] 폰 브라우저로 `http://<IP>:5001/api/status` 직접 접속했을 때 JSON이 뜨는가?
- [ ] `AndroidManifest.xml`에 `usesCleartextTraffic="true"` 들어있는가?
- [ ] 설정 화면에서 저장한 IP가 라즈베리파이의 실제 IP와 일치하는가? (`hostname -I`로 재확인)
- [ ] 에러 메시지가 타임아웃인가, 아니면 다른 에러인가? (`.timeout()` 없으면 로딩 스피너가 무한정 돎)
