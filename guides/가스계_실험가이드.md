# 가스계 실험 가이드 — 조립부터 실험까지

> 이 문서 하나만 보고 가스계 소화설비(CO2 소화설비) 모듈을 처음부터 끝까지 완성할 수 있게 정리했습니다.

---

## 0. 목표 정리

**법정/실무 기준**: CO2 저장용기는 중량손실 **10% 미만**이 정상 (출처: 소방시설등 점검관리 매뉴얼 — 이산화탄소소화설비 점검표 9-B, "이산화탄소는 중량 손실 10% 미만")

**우리 시스템이 하는 일**: 로드셀로 용기 무게를 상시로 재서, 초기 대비 손실률이 서서히 10%에 다가가는 추세를 보고 재충전 시점을 미리 예측

**⚠️ 중요 — 압력이 아니라 중량 기준**: CO2는 고압식이면 액체+기체 평형 상태라 손실이 있어도 압력이 거의 안 변합니다. 반드시 중량으로 재야 합니다.

---

## 1. 준비물

- ESP32 DevKitC × 1
- 평판 하프브릿지 로드셀 (화물지킴이 재고 재사용) × 2
- HX711 로드셀 앰프 모듈 × 1
- 받침판(용기가 얹힐 평판), 고정 프레임
- 미니어처 CO2 용기 모형(또는 임의의 물체)
- 알고 있는 무게의 물건(동전, 저울로 잰 물건) — 스케일 보정용

---

## 2. 조립 순서

1. 로드셀 2개를 평판 양 끝에 배치 — 한쪽 끝은 고정 프레임에, 다른 쪽 끝(하중측)에 받침판을 얹는 구조
2. 두 로드셀의 같은 극성 단자끼리 병렬 연결 (E+끼리, E-끼리, S+끼리, S-끼리)
3. 그 묶음을 HX711 1개에 연결 (E+/E-/S+/S− → HX711 해당 핀)
4. HX711 배선: DT→ESP32 GPIO16, SCK→GPIO17, VCC→3.3V, GND→GND
5. 받침판 위에 미니어처 CO2 용기 모형(또는 임의의 물체) 올리기

**배치 포인트**: 용기가 받침판 중앙에 오도록 놓아야 두 로드셀이 하중을 균등하게 나눠 받습니다.

---

## 3. 캘리브레이션 (실험 전 필수)

1. 코드 업로드 후 **영점(0점) 캘리브레이션** — 아무것도 안 올린 상태에서 0으로 맞추기
2. **알고 있는 무게**(동전, 저울로 잰 물건 등)를 올려서 실제 무게와 센서값이 맞는지 스케일 보정 (`CALIBRATION_FACTOR` 조정)
3. **공병중량 별도 측정** — 용기만 단독으로(약제 없이) 올려서 나온 값을 `EMPTY_CONTAINER_WEIGHT`로 코드에 상수 저장
4. **최초 설치 시 총중량** 기록 (용기+약제, 여러 번 읽어서 평균)

### ⚠️ 계산 시 주의 — 총중량이 아니라 약제중량 기준

받침판에 얹힌 총중량(용기+약제)을 그대로 "초기값 대비 %"로 계산하면, 용기 자체의 고정된 무게 때문에 손실률이 실제보다 작게 나오는 오류가 생깁니다.

```python
EMPTY_CONTAINER_WEIGHT = 0.0  # 3단계에서 측정한 공병중량(g)

def co2_loss_ratio(current_total_weight, initial_total_weight):
    initial_agent_weight = initial_total_weight - EMPTY_CONTAINER_WEIGHT
    current_agent_weight = current_total_weight - EMPTY_CONTAINER_WEIGHT
    loss_ratio = (initial_agent_weight - current_agent_weight) / initial_agent_weight * 100
    return loss_ratio  # 10% 이상이면 재충전 판정
```

---

## 4. 동작 확인

1. 시리얼 모니터로 현재 총중량, 손실률(%), 상태(정상/주의/재충전필요)가 정상 표시되는지 확인
2. 받침판 위 물건을 조금씩 덜어내면서 손실률이 그에 맞게 오르는지, 10% 근처에서 "재충전 필요"로 바뀌는지 확인

---

## 5. 실험 프로토콜

### 5-1. 손실 추세 재현 (회귀분석용 데이터)

1. 초기중량 기록 (캘리브레이션 3~4단계와 동일)
2. 일정 시간 간격(예: 몇 분~몇 시간)마다 소량씩 무게를 덜어내며 측정 — 실제 누설처럼 점진적인 변화를 재현
3. 매 측정마다 시각과 손실률을 기록

**기록 양식**
```

```

### 5-2. 10% 임계치 도달 시연

받침판 무게를 서서히 줄여서 손실률이 10%를 넘는 순간 시스템이 "재충전 필요" 상태로 정확히 전환되는지 확인합니다. 시연 영상에 쓸 핵심 장면입니다.
