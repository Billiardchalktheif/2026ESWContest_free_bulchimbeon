# 수계(주펌프+충압펌프) 배관 구조 최종 가이드

**작성일**: 2026-08-14
**근거**: 소방설비기사 수계소화설비 계통도 및 NFTC 102 2.3.7 (펌프 성능시험배관 적합기준)
**목적**: 실제 가압송수장치 구조를 최대한 재현한 POC 배관 설계

---

## 1. 최종 배관 구조도

```
주펌프    → [분기티①] ─┬→ [체크밸브①] ─┐
                        └→ 성능시험배관A │
                                          ├→ [합류티] → 헤더 → 압력센서(곁가지) → 니들밸브(방수구 대용) → 배출
충압펌프  → [분기티②] ─┬→ [체크밸브②] ─┘
                        └→ 성능시험배관B
```

- 성능시험배관A/B 구성(각각 동일): 유량센서(직렬) → 압력센서(곁가지, 티) → 니들밸브(유량조절)

### 핵심 설계 원칙
1. **분기는 체크밸브보다 반드시 앞(펌프 쪽)에 위치.**
   체크밸브 뒤에서 분기하면, 정상운전 경로를 잠갔을 때 체크밸브 앞에 압력이 갇혀
   성능시험배관 쪽으로 흐르지 못하게 됨.
2. **체크밸브는 "헤더로 가는 정상운전 경로"에만 설치.** 성능시험배관 쪽에는 체크밸브 불필요
   (NFTC 계통도 기준으로도 성능시험배관엔 체크밸브 없음).
3. **압력센서는 헤더에 1개(공용).** 실제 배관계 압력을 감시해 릴레이 자동제어(충압/주펌프 기동)에 사용.
4. **주배관 끝단(헤더 이후)에는 체크밸브 불필요.** 역류를 막아야 할 대상이 이미 앞단에서 처리됨.

## 2. 부품 리스트

| 부품 | 개수 | 규격/비고 |
|---|---|---|
| 분기 티 | 2개 | 8mm 원터치 피팅, 주펌프/충압펌프 각 토출구 직후 |
| 체크밸브 | 2개 | 8mm 원터치 피팅(정수기용), 화살표 방향 = 헤더 방향으로 장착 |
| 합류 티 | 1개 | 8mm 원터치 피팅 |
| 압력센서용 티 | 1개 (기존 보유) | 헤더에 곁가지로 장착 |
| 유량센서 (YF-S201) | 1~2개 | 정석은 2개(펌프별 개별), 절충 시 1개+수동 밸브 전환 |
| 니들밸브 | 최소 2개 이상 | 성능시험배관용(A/B), 헤더 말단 배출조절용 |
| 튜브(펌프 동봉품) | 기존 보유 | - |

> 실제 표준 구조의 물올림수조/스트레이너/후트밸브/릴리프밸브/압력챔버 등은
> 소형 POC 특성상 생략 (보고서에 간소화 사유 명시 권장).

---

## 3. 운영 모드 두 가지 (밸브 조작으로 전환)

동일한 전류센서(INA219)로 두 가지 성격이 다른 데이터를 뽑을 수 있음. 물의 경로(밸브 개폐)만 다름.

### 모드 A — 성능시험 모드 (H-Q 곡선, 유량-압력 관계 측정)
- 헤더 방향 니들밸브(또는 해당 경로 밸브) **폐쇄**
- 해당 펌프의 성능시험배관 니들밸브 **개방**
- 물이 성능시험배관으로만 흐름 → 유량센서+압력센서로 (전류, 압력, 유량) 세트 기록
- 대상 펌프 단독 시험 (주펌프 시험 시 충압펌프는 정지)

### 모드 B — 정상운전 모드 (충압펌프 작동빈도/반응성 시연)
- 성능시험배관 니들밸브 **폐쇄**
- 헤더 방향 경로 **개방** (체크밸브 통과)
- 헤더 니들밸브(방수구 대용)를 살짝 열어 배관계에 일정한 소모(누수/방수 흉내)를 만들어 압력 하강 유도
- 헤더의 압력센서가 임계값 이하로 떨어지면 → ESP32가 릴레이로 충압펌프 자동기동
- 이 순간 충압펌프의 기동 전류파형(INA219) 기록 → "작동빈도/반응성 데이터"로 사용
- 충압펌프로도 압력 유지가 안 되면 주펌프까지 자동기동 (2단계 임계값 로직)

## 4. ESP32 제어 로직 (모드 B 기준, 릴레이 도착 후 적용)

```cpp
// 헤더 압력센서 값 기준 2단계 임계값 제어
float pressure = readPressureSensor();

if (pressure < CHUNGAP_START_THRESHOLD) {
  digitalWrite(CHUNGAP_RELAY_PIN, HIGH); // 충압펌프 기동
}
if (pressure >= CHUNGAP_STOP_THRESHOLD) {
  digitalWrite(CHUNGAP_RELAY_PIN, LOW);  // 충압펌프 정지
}
if (pressure < MAIN_START_THRESHOLD) {   // 충압으로도 못 따라갈 만큼 하강
  digitalWrite(MAIN_RELAY_PIN, HIGH);    // 주펌프 기동
}
if (pressure >= MAIN_STOP_THRESHOLD) {
  digitalWrite(MAIN_RELAY_PIN, LOW);     // 주펌프 정지
}
```

- 임계값(THRESHOLD)은 실측 캘리브레이션으로 결정 필요
- 릴레이 도착 전까지는 모드 B도 수동 스위치로 동일하게 재현 가능
  (사람이 압력값 보고 손으로 충압펌프 전원 on/off)

## 5. 조립 시 체크리스트

- [ ] 체크밸브 화살표 방향 = 펌프 → 헤더 방향 (역방향 장착 시 물 안 흐름)
- [ ] 압력센서는 수평 장착 시 초기 기포 벤팅 필요 (물 채울 때 천천히, 톡톡 쳐서 기포 제거)
- [ ] 유량센서 화살표 방향 확인 후 장착
- [ ] 조립 완료 후 저압에서 전체 누수 테스트 먼저 진행 → 이상 없으면 정격압까지 서서히 상승
- [ ] 펌프 정격양정/유량 스펙 확인 후, 부속 손실 감안해 실측 압력/유량이 정상 범위인지 1차 확인
  (압력·유량이 비정상적으로 약하면 체크밸브 개방압 부족 또는 부속 손실 과다 의심)

## 6. 데이터 수집 계획 (요약)

| 데이터 종류 | 수집 모드 | 필요 시점 |
|---|---|---|
| 펌프 H-Q 성능곡선 (정상 클래스 학습데이터 겸용) | 모드 A | 밸브 스윕(5~6단계) × 전압 스윕(2~3단계) |
| 이상 조건 파형 (비정상 클래스) | 모드 A 변형 | 흡입측 막음, 극단적 폐색 등 인위 조건 |
| 충압펌프 작동빈도/반응성 파형 | 모드 B | 헤더 압력 하강 유도 후 자동기동 전류파형 |

---

## 요약

> 분기 → 체크밸브(헤더 경로만) → 합류 → 헤더(압력센서) 순서가 확정 구조.
> 성능시험배관은 체크밸브보다 앞, 펌프 바로 뒤에서 분기.
> 동일 전류센서로 밸브 전환만으로 "성능곡선용 데이터"와 "작동빈도 데이터"를 모두 수집 가능.
