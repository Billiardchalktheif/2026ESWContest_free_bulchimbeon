# 불침번 — 엣지별 캘리브레이션 · 데이터축적 통합 정리

> 5개 엣지(`guides/*_실험가이드.md`)와 `AI_학습_데이터_수집_가이드.md`에 흩어진 "실험 전 캘리브레이션"과 "실험 데이터 축적" 항목을 한 곳에 모은 요약/체크리스트입니다. **각 항목의 상세 배선·절차는 해당 `guides/` 파일을 참고하세요** — 이 문서는 "무엇을, 왜, 얼마나" 축적해야 하는지 빠르게 파악하기 위한 인덱스입니다.

## 분류 기준

실험은 목적에 따라 세 종류로 나뉩니다. 셋을 섞으면 "지금 하는 게 캘리브레이션인지 데이터 축적인지" 헷갈리기 쉬워서 명확히 구분합니다.

| 구분 | 의미 | 특징 |
|---|---|---|
| **① 캘리브레이션/동작확인** | 센서·회로가 정상 동작하는지, 기준값(영점·임계값)을 잡는 1회성 작업 | 실험 시작 전 반드시 선행. 반복 축적 아님 |
| **② 추세 데이터 축적** | 라벨링 불필요, 값의 변화 경향을 회귀분석용으로 계속 쌓는 작업 | 사람이 정답을 안 붙여도 됨. 시간 될 때마다 계속 |
| **③ AI 학습 데이터 축적** | 라벨(정답)이 붙은 데이터를 모아 분류 모델을 학습시키는 작업 | 자동 라벨링(수계) vs 수동 라벨링(자탐2)으로 방식이 다름 |

**실제로 AI 분류 모델이 필요한 곳은 자탐2와 수계, 둘뿐입니다.** 가스계·유도등은 임계값이 이미 법정 기준으로 정해져 있어 추세만 쌓으면 되고, 소화기는 규칙 기반(임계값+연결상태) 판정이라 반복은 "검증"이지 "학습"이 아닙니다.

| 엣지 | ① 캘리브레이션 | ② 추세 축적 | ③ AI 학습 축적 |
|---|---|---|---|
| 가스계 | 영점·스케일·공병중량 | 손실률 추세 (지속) | — |

| 유도등 | 구동전압·자동전환 확인 | 전압 방전 추세 (지속) | — |

| 자탐2(광전식) | ADS1115+MQ-2+DHT22 확인 | — | fire/cooking/normal (수동라벨) |

## Part 1. 캘리브레이션 / 동작확인 (실험 전 필수, 1회성)

### 가스계
- 영점(0점) 캘리브레이션 — 무부하 상태에서 0으로 설정
- 알고 있는 무게로 스케일 보정 (`CALIBRATION_FACTOR`)
- **공병중량 별도 측정** → `EMPTY_CONTAINER_WEIGHT` 상수 저장 (총중량이 아니라 **약제중량 기준**으로 계산해야 손실률 오차가 안 생김)
- 최초 설치 시 총중량 기록 (여러 번 읽어 평균)
- 10% 임계치 전환("재충전 필요") 동작 확인 1회

### 소화기
- **정지 상태 기준값 캘리브레이션** — 실물마다 설치 각도가 달라 중력에 의한 가속도 값이 다름. 부착 직후 몇 초간 측정해 기준값으로 저장 (절대값 하드코딩 금지), 4개 노드 각각 진행
- **이벤트 감지 임계값 설정** — 정지 상태 노이즈 최댓값을 확인하고, 그 2배 정도를 임계값으로 설정 (너무 낮으면 가만히 있어도 오탐)
- 게이트웨이 ESP-NOW 페어링 확인

### 수계
- INA219 #1(충압, 0x40)·#2(주펌프, 0x41) 두 값이 각각 정상 구분되는지 확인 (주소 충돌 시 A0 패드 점퍼 재확인)
- 압력센서 분압값이 정상 범위(0~50kPa대)로 나오는지 확인
- 릴레이 CH1/CH2 on/off로 펌프 실제 구동 확인
- **⚠️ 최우선 물리검증**: 니들밸브 체절 vs 부하 상태에서 전류값 비교 1회 — 소형 DC펌프는 원심펌프와 반대로 체절(막힘) 시 전류가 더 높을 수 있어, 실측으로 방향을 확정해야 이후 AI 라벨링 방향이 정해짐. 결과는 팀 채팅방에 "체절이 [높다/낮다]" 한 줄 공유

### 유도등
- **적정 구동전압 실측** — 파워서플라이로 0.5V부터 서서히 올리며 점등 지점 탐색 (박스 표기 DC1.2V는 셀 1개 기준이라 그대로 쓰면 안 됨)
- **배터리 자동전환 검증** — 전원 차단 시 LED가 계속 켜져 있는지로 DC직결 방식/AC220V 방식 분기 결정 (분기점, 반드시 선행)
- ESP32 저항분압 값이 배터리 전압대(3.x V)로, CDS 값이 점등/소등에 따라 확연히 달라지는지 확인

### 자탐1(차동식) / 자탐2(광전식)
- ADS1115 + TS0202(자탐1) / MQ-2+DHT22(자탐2) 값이 시리얼 모니터에 정상 범위로 나오는지 확인
- MQ-2는 예열시간 필요 — 값 안정화까지 대기 후 실험 시작
- 감지기 모형은 전기적 연결 없이 챔버에 물리적으로 배치만 (전시용, 실제 측정은 별도 센서가 담당)

## Part 2. 추세 데이터 축적 (라벨 불필요, 계속 쌓기)

### 가스계 — 손실률 추세
- 일정 시간 간격(분~시간 단위)마다 소량씩 무게를 덜어내며 측정 → 실제 누설처럼 점진적 변화 재현
- 기록: 측정 시각 / 현재중량 / 손실률(%)
- 오늘 몇 개만 찍어보고, 이후 며칠에 걸쳐 계속 축적하면 됨 (회귀분석 재료)

### 유도등 — 전압 방전 추세
- 완충 → 방전 사이클을 반복, ESP32가 10~30초 간격으로 전압을 자동 기록
- 방전시간 실측 1회(스톱워치, 스펙 60분·법정기준 20분 대비 검증)도 별도로 진행
- **완성 즉시 바로 로깅 시작 권장** — 트렌드 데이터라 시작이 늦어질수록 확보량이 줄어듦

### 자탐1(차동식) — 열원반응 재현성
- 평상시 베이스라인 1분 확보 → 열풍기 20cm 거리에서 10초 조사 → 온도 상승률(°C/초) 기록
- 완전히 식을 때까지 대기 후 다음 시행
- 최소 10회 반복, 조건(거리·시간) 동일하게 유지해 재현성 확인 (AI 라벨링이 아니라 dT/dt 계산 검증용)

## Part 3. AI 학습 데이터 축적 (라벨 필요)

### 수계 — 펌프 전류 파형 분류 (자동 라벨링)
- 압력센서가 체절/부하 상태를 스스로 감지해 **자동으로** 라벨을 붙임 → 사람이 라벨을 따로 적을 필요 없음
- **목표**: 체절, 부하 각 최소 30~50회 (사이클당 30초~1분)
- **공회전은 별도 시나리오**: 탱크 물을 일부 비우거나 흡입측 호스를 살짝 들어 무급수 구동 재현 (밸브 조작이 아니라 급수 조건 변경)
- 30개 이상 모이면 `ml/train_pump_classifier.py` 바로 실행 가능 (이미 검증된 스크립트)

### 자탐2(광전식) — 비화재보 판별 (수동 라벨링)
- 화재/조리연기는 사람이 만드는 상황이라 센서가 스스로 라벨을 못 붙임 → **시작/종료 시각을 사람이 기록** 후 시간대 기준으로 일괄 라벨 적용

| 상태 | 재현 방법 | 지속시간 |
|---|---|---|
| `fire` | 열풍기 조사 + 발연원(향) 동시 투입 | 2~3분 |
| `cooking` | 가습기/전기포트 수증기 | 2~3분 |
| `normal` | 무조작 대기 | 2~3분 |

- **한 번에 한 상태만 재현** (섞이면 라벨 애매해짐)
- 각 상태 최소 15~20회 세션 목표, 시간대·발연원 세기를 다양화하면 좋음
- 기록 후 `server/label_by_time_range.py "시작시각" "종료시각" 라벨` 로 DB 일괄 라벨링
- 30개 이상 모이면 `ml/train_nuisance_classifier.py` 실행

## Part 4. 반복 검증 (학습 아님, 규칙기반 판정 신뢰도 확인)

### 소화기 — 오탐/이탈 시나리오
임계값 자체는 Part 1에서 이미 확정. 아래는 그 임계값 기반 판정 로직이 실제로 일관되게 작동하는지 확인하는 반복 검증입니다 (AI 학습용 데이터 축적 아님).

- **오탐(단순 접촉)**: 살짝 건드림 → 가속도 이벤트 발생, 게이트웨이 연결 유지 → 일정 시간 후 "무시" 판정 확인
- **진짜 이탈**: 통신 범위 밖 이동(또는 전원 차단) → 가속도 이벤트 + 연결 두절 → "이탈 확정" 판정 확인
- 각 시나리오 최소 5~10회 반복, 판정 일관성 확인
- (선택) 배터리 소모 실측 — 완충 후 하루 방치, 전압 강하 확인

### 수계 — 충압펌프 기동빈도 (보조 지표)
- 니들밸브를 살짝만 열어 미세누수 흉내 → 충압펌프 기동 빈도(전류 0→값 있음 전환 횟수)를 완전 밀폐 상태와 비교

## 진행 순서 제안 (병행 가능한 항목 구분)

1. **완성되는 엣지부터 Part 1(캘리브레이션) 먼저 완료** — 모든 실험의 전제조건
2. **자탐2, 수계**: Part 1 끝나면 즉시 Part 3(AI 라벨링 데이터) 착수 — 반복 횟수가 많아 가장 먼저 시작해야 함
3. **가스계, 유도등**: Part 1 끝나면 즉시 Part 2(추세 로깅) 시작 — 특히 유도등은 시간이 걸리는 트렌드 데이터라 완성 즉시 백그라운드로 계속 로깅
4. **소화기**: Part 1(임계값 캘리브레이션) 후 Part 4(반복 검증) — 오늘 3~5회만 하고 나머지는 이후 진행해도 무방
5. 모든 항목은 여러 팀원이 엣지별로 나눠 병행 가능 — 기록 양식(시각/값/상태)만 통일하면 나중에 합치기 쉬움
