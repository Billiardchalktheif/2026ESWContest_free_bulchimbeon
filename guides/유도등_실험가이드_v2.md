# 유도등 실험 가이드 — 배터리 열화감지 전용 (v2, CDS 제거)

> 이 문서 하나만 보고 유도등 스코프를 처음부터 끝까지 완성할 수 있게 정리했습니다. 순서대로 진행하세요.
>
> **v1 대비 변경점**: CDS 조도센서(점등확인용) 제거. 유도등은 LED라 조도값이 열화 예측 회귀분석에 기여하지 않고, 배터리 전압 트렌드만이 우리 시스템의 핵심 가치(사전 예측)이므로 스코프를 배터리 전압 감시로 단일화함. 이에 따라 멀티플렉서(CD74HC4067)도 제거 — ESP32 ADC 핀에 유도등 개수만큼 직결하는 구조로 단순화.

---

## 0. 목표 정리

**법정 기준**: 유도등 비상전원(배터리)은 정전 후 **20분 이상** 점등 유지해야 함
**우리 시스템이 하는 일**: 배터리 전압을 상시로 재서, 서서히 떨어지는 추세를 보고 "이 배터리가 곧 20분 기준을 못 채우겠다"를 미리 예측
**오늘 목표**: 실물 유도등 1대의 배터리 전압을 ESP32로 읽을 수 있는 상태까지 완성

**스코프 확정 사항**: 점등 여부(조도) 확인은 하지 않음. LED 자체 고장이나 접촉불량 같은 "이미 발생한 이후"의 이진(binary) 신호는 회귀예측 데이터로 쓸 수 없고, 육안 점검으로도 쉽게 확인되는 항목이라 시스템 스코프에서 제외.

## 2. 내부 구조 확인 (실물 기준 정리)

실제 뜯어본 결과, 배터리는 낱개 건전지 형태가 아니라 **Ni-Cd 셀을 직렬로 묶어 열수축튜브로 감싼 배터리팩**이며, 흰색 플라스틱 배터리홀더에 **스프링클립 방식**으로 장착되어 있음 (커넥터 방식 아님).

**보드 구성 (사진 기준)**
- PCB 상단 우측 2핀 커넥터(H RED BK 표기) — 이 보드 버전에서는 미사용. 보유 중인 노란 Ni-Cd 예비배터리는 이 커넥터용으로, **이번 배터리홀더 방식과는 호환 안 됨 → 사용하지 않음**
- 실제 사용 중인 배터리 = 주황색 원통형("GREEN-POWER"), 홀더 클립에 꽂혀 있음
- PCB 상단에서 나오는 백/적/흑 굵은 3가닥 전선 = **AC220V 입력선** (배터리 아님, 절대 tap 지점 아님)
- PCB 중앙 LED 모듈(LD1~LD9) = 결선도 표기 "2선식/3선식" 참고용, 이번 스코프에서는 건드리지 않음

**⚠️ 안전 주의**: 변압기(노란 코일), 퓨즈, AC220V 입력선 근처는 절대 작업하지 않음. 배터리 클립은 그보다 물리적으로 떨어진 저전압 구간.

## 3. 1단계 — 적정 구동전압 찾기

**절대 원칙: 절대 220V 콘센트에 바로 꽂지 마세요.** 저전압 DC 경로로 접근합니다.

### 배선
- 3선(백/흑/적) 중 **백/흑 2개만** 사용 (2선식 결선도 기준)
- 적선은 이번 단계에서 연결하지 않고 절연 마감

### 전압 탐색 절차
1. 파워서플라이 **전류 제한을 0.1~0.2A로 낮게 설정**
2. 출력전압 **0.5V부터 시작**, 0.2~0.3V씩 천천히 올림
3. LED가 켜지는 지점 발견 시 즉시 멈추고 전압 기록
4. 발열/이상 냄새 시 즉시 전원 차단

### 기록
```
정상 점등 확인 전압: _____ V
이때 전류: _____ A
```

---

## 4. 2단계 — 배터리 자동전환 검증

### 테스트
1. LED 켜진 상태에서 파워서플라이 출력을 **갑자기 차단**
2. LED가 **그대로 계속 켜져 있는지** 관찰

**✅ 계속 켜져 있으면** → 5단계로 진행 (DC 저전압 방식 확정)
**❌ 꺼지면** → AC220V 방식 필요 (안전수칙 준수하며 멀티탭 경유 전환, 기존 절차 동일)

---

## 5. 3단계 — 배터리 전압 실측 (★ 신규 추가, 회로 설계 전 필수)

기존 문서는 "3.6V Ni-Cd" 를 전제로 R1=R2=10kΩ을 가정했으나, 실물이 예상과 다를 수 있으므로 **반드시 먼저 실측**합니다.

1. 멀티미터 DC 전압 모드
2. **배터리를 뽑지 않은 상태로**, 배터리홀더 스프링클립 양 끝(+/-)에 탐침을 대고 측정
3. 완충 상태 기준값 기록

```
배터리 홀더 클립 양단 실측 전압: _____ V
```

### 실측값에 따른 분압 저항 결정

| 실측 전압대 | 추정 구성 | 저항비 (R1 : R2) | 비고 |
|---|---|---|---|
| 약 3.6~4.2V | 셀 3개 직렬 | 10kΩ : 10kΩ (2배 환산) | 기존 가정과 일치, 그대로 진행 |
| 약 4.8~5.5V | 셀 4개 직렬 | 15kΩ : 10kΩ (2.5배 환산) | 재계산 필요 |
| 약 1.2~1.5V | 셀 1개 단독 | 분압 불필요, 직결 검토 | ESP32 ADC 한계(3.3V) 이하라 분압 자체가 불필요할 수 있음, 신호가 작아 노이즈 대비 재검토 필요 |

실측값이 표에 없는 다른 값이면 저항비 재계산이 필요하니 팀 채팅방에 공유.

---

## 6. 4단계 — ESP32 연동 (배터리 전압만, 단일 유도등 기준)

배터리(빨간 내장 배터리) **홀더 클립에 병렬로 가지선을 따서** ESP32로 가져옵니다. 원래 회로는 끊지 않습니다.

### 배선 (단일 유도등 기준, 브레드보드)

| 부품 | 연결 |
|---|---|
| 저항분압 입력 | 배터리 홀더 클립(+) 지점에서 분기 |
| 저항분압 출력 | ESP32 **GPIO34** (ADC1) |
| 저항분압 GND | 배터리 홀더 클립(-), ESP32 GND와 공통 |

```
배터리(+) 클립 ──┬── (원래 유도등 회로, 손대지 않음)
                  │
                 R1
                  │
                  ├──── ESP32 GPIO34
                  │
                 R2
                  │
배터리(-) 클립 ──┴── ESP32 GND
```

### 확인
코드 업로드 후 시리얼 모니터에서:
- 저항분압 → 배터리 전압값이 3단계 실측값과 비슷하게 표시되는지 (예: 3.6V대 실측이면 코드 환산값도 3.6V대로 나와야 함)

---

## 7. 5단계 — 실험 프로토콜 (데이터 수집)

### 7-1. 방전시간 실측 (스펙 검증용)
1. 배터리 완충 상태 확인
2. 정상 전원 차단 (2단계와 동일한 방식)
3. **스톱워치로 LED가 실제로 꺼지는 순간까지 시간 측정**
4. 기록: `측정 방전시간: _____ 분` (법정기준 20분과 비교)

### 7-2. 전압 추세 로깅 (예측 모델용 — 계속 반복)
완충 → 방전 사이클을 반복하면서 ESP32가 전압을 주기적으로(예: 10~30초마다) 기록하도록 둡니다. 이 데이터가 "전압이 서서히 떨어지는 추세 → 며칠 후 기준 미달 예상" 회귀분석의 재료가 됩니다.

**기록 양식**:
```
실험 일시: 2026-08-XX
사이클: 1회차
완충 시작 전압: ___ V
방전 시작 시각: ___
방전 종료 시각(LED 꺼짐): ___
총 방전시간: ___ 분
비고:
```

### 7-3. 배터리 충전 방법
- 이 유도등 원래 회로(AC220V 또는 확정된 DC 경로)로 다시 충전

## 8. 4개로 확장할 때 (오늘 안 해도 됨)

CDS와 멀티플렉서를 뺐기 때문에, 채널 수가 4개(전압만)로 줄어 **ESP32 ADC 핀에 직결하는 구조로 단순화됨**.

- 유도등 4대 각각의 분압회로 출력을 ESP32의 서로 다른 ADC 핀에 직결 (예: GPIO32, 33, 34, 35)
- 멀티플렉서 불필요 (ADC 핀 4개면 충분)
- 단일 유도등용 배선을 그대로 4번 복제하면 됨, 저항분압 회로 자체는 재사용

**파워서플라이 병렬 연결 (4대 동시 테스트 시)**
- 파워서플라이 출력을 각 유도등에 병렬로 분배 (터미널블럭 권장)
- 유도등끼리 직접 연결하는 게 아니라, 전원 공급원만 공유하는 것
- **전류 제한값을 4대 분량으로 상향 조정 필수** (1대 전류값 × 4로 계산, 파워서플라이 최대 출력 스펙도 확인)
