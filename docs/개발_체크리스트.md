# 불침번 개발 체크리스트 (순서대로, 날짜 고정 없음)

> 요일 박아두지 않고 순서만 정리했어요. 진행 속도 맞춰서 하나씩 체크하면서 쓰면 돼요. 모임 때 "지금 여기까지 왔다"만 확인하는 용도로 쓰기 좋을 것 같아요.

---

## 0단계 — 재료 손질 (받자마자 몰아서)

- [ ] 부품 전수검사 (개수·파손 확인, 멀티미터로 기본 통전 체크)
- [ ] 납땜 몰아치기: TP4056 소켓 4개, SH1.25 케이블 연결 4세트, HX711-로드셀 배선
- [ ] 저항분압 회로 사전 제작 (수계 압력센서용 1개, 유도등 배터리용 4개)
- [ ] 전선 손질: 점퍼선 길이별 절단·피복, INA219 리드선 정리
- [ ] 로드셀 영점/스케일 캘리브레이션
- [ ] ESP32 보드 전체에 기본 펌웨어(WiFi 연결 테스트용) 업로드 + 라벨링(자탐1용/자탐2용/수계용...)
- [ ] 배터리 전수 충전 (LiPo 4개, Ni-Cd 유도등용)

---

## 1단계 — 모듈 개별 검증 (브레드보드, 통합 전)

- [ ] 자탐1(차동식): ESP32+ADS1115+TS0202 배선, 열풍기 반응 확인
- [ ] 자탐1: 루프저항 회로(고정저항+감지기모형) 추가, 값 확인
- [ ] 자탐2(광전식): MQ-2+DHT22 배선, 가습기/발연원 반응 테스트
- [ ] 자탐2: 루프저항 회로 추가, 챔버 배치
- [ ] 가스계: 로드셀 2개 병렬 + HX711 연결, 무게값 확인
- [ ] 유도등: 멀티플렉서 배선, 조도센서 1개로 채널 스위칭 테스트
- [ ] 유도등: 나머지 채널 배선(조도×4, 저항분압×4)

---

## 2단계 — 수계 핵심 검증 (제일 중요, 최우선)

- [ ] 배관 조립 (탱크+펌프+호스+T피팅+압력센서)
- [ ] 릴레이 배선, INA219 배선(충압/주펌프)
- [ ] **⚠️ 체절 vs 부하 전류 실측** — 밸브 잠금/개방 각각 INA219값 기록해서 물리 가정(체절=고전류인지) 확정
- [ ] 실측 결과로 라벨링 방향 확정, 성능시험 로직 코드 초안

---

## 3단계 — 소화기

- [ ] 리프노드 1호기 조립(ESP32-C3+MPU6500+LiPo+TP4056), 검증
- [ ] 리프노드 2~4호기 반복 조립(1호기 배선 그대로 복제)
- [ ] 게이트웨이 설정, 리프노드↔게이트웨이 ESP-NOW 통신 테스트

---

## 4단계 — 서버 + 데이터 축적

- [ ] 라즈베리파이 초기 세팅, UDP 리시버 뼈대 작성
- [ ] DB 스키마 구축, 자탐1·2부터 서버 연동
- [ ] 나머지 모듈(수계/가스계/유도등)도 서버 연동 — 전 모듈 데이터 DB 적재 확인
- [ ] 수계 성능시험 반복 실행 → INA219 파형 라벨 데이터 축적
- [ ] 자탐2 오작동 판별용 데이터 축적(정상/수증기/연기 각각 반복 측정)
- [ ] 회귀분석 함수(자탐 배선추세, 유도등 배터리추세, 가스계(CO2) 10%예측) 작성·적용
- [ ] 펌프 파형 분류 모델 1차 학습
- [ ] 자탐2 오작동 분류 모델 1차 학습
