# 불침번 — AI 학습 데이터 수집 가이드

> 하드웨어 조립이 끝난 모듈부터 바로 시작할 수 있어요.  — 데이터 수집은 이미 검증된 서버 파이프라인만으로 충분합니다.

---

## 왜 이 문서가 필요한가

두 AI 모델(자탐2 비화재보 판별, 수계 파형분류)은 "정답이 뭔지 알려주는 데이터"가 있어야 학습됩니다. 근데 이 둘은 **라벨 붙이는 방식이 완전히 다릅니다.**

||라벨을 누가/어떻게 붙이나|
|---|---|
|**수계**|압력센서가 체절/부하 상태를 스스로 감지해서 **자동으로** 라벨을 붙임|
|**자탐2**|화재/조리연기는 사람이 인위적으로 만드는 상황이라 센서가 스스로 알 방법이 없음 → **사람이 기록해야 함**|

이 문서는 두 경우를 어떻게 처리하는지, 그리고 **자탐2용 수동 라벨링 절차**를 다룹니다.

---

## 1. 수계 — 조립가이드 그대로 반복하면 끝

`테스트베드_조립가이드.md` 3장의 9~11단계(니들밸브 잠금→압력측정→열기→압력측정)를 **여러 번 반복**하면 됩니다. 별도로 라벨을 적어둘 필요가 없습니다 — 서버가 압력값이 급상승하는 구간을 보고 자동으로 "지금 체절 상태다"를 판단해서, 그 순간의 CT클램프 전류값에 라벨을 자동으로 붙입니다.

### 반복 횟수 목표

- 체절(과부하 상당), 부하(정상 상당), 공회전 각각 **최소 30~50회**
- 한 번 사이클(잠금→측정→열기→측정)에 30초~1분 정도면 충분합니다
- **공회전은 별도 시나리오**입니다 — 탱크 물을 일부 비우거나 흡입측 호스를 살짝 들어서 펌프가 물 없이 도는 상황을 만들어주세요 (밸브 조작이 아니라 급수 조건을 바꾸는 것)

### 확인할 것 (조립가이드에서 이미 강조된 부분)

**체절 상태 전류가 실제로 부하 상태보다 높게 나오는지 낮게 나오는지 제일 먼저 확인하세요.** 반대로 나와도 문제없습니다 — 라벨만 반대로 바꾸면 되니까요. 다만 이건 사람이 판단할 게 아니라 실측 후 팀 채팅방에 "체절이 [높다/낮다]로 나왔음" 한 줄만 공유해주시면 됩니다.

## 2. 자탐2 — 수동 라벨링이 필요합니다 (핵심)

### 왜 사람이 직접 기록해야 하나

수계는 압력센서가 "지금 체절 상태"라는 걸 물리적으로 확인해주지만, 자탐2는 **온도·가스·습도 센서가 "이건 화재고 이건 조리연기다"를 스스로 구분하지 못합니다.** 애초에 그 구분을 학습시키는 게 목적이니까요. 그래서 **"지금부터 몇 분 동안은 화재 상황을 재현 중이다"를 사람이 시간과 함께 기록해두고, 나중에 그 시간대의 데이터에 일괄로 라벨을 붙이는 방식**을 씁니다.

### 실험 절차

**한 번에 한 상태만 재현하세요.** 상태가 섞이면 라벨이 애매해집니다.

|상태|재현 방법|지속 시간|
|---|---|---|
|`fire` (화재)|열풍기를 챔버에 쏘고, 동시에 발연원(향)으로 연기 추가|2~3분|
|`cooking` (조리연기)|가습기/전기포트로 챔버 안에 수증기 발생|2~3분|
|`normal` (평상시)|아무 조작 없이 대기|2~3분|

**기록 양식** (실험할 때마다 이렇게 적어두세요 — 종이든 메모앱이든 상관없습니다):

```
실험 일시: 2026-08-XX
상태: fire
시작 시각: 14:32:10
종료 시각: 14:35:00
비고: 열풍기 세기 강, 발연원 추가 30초 후 투입
```

**⚠️ 안전 주의사항**

- 열풍기·발연원 사용 시 환기 확보 (실내 화재경보기가 있는 공간이면 오작동 주의)
- 발연원(향)은 불씨 관리 철저히, 다 쓰면 확실히 꺼졌는지 확인
- 가습기는 전자부품(ESP32, ADS1115)에 직접 물방울 튀지 않게 거리 유지

### 반복 횟수 목표

- 각 상태(fire/cooking/normal)당 **최소 15~20회 세션** (한 세션 = 2~3분)
- 시간대를 다르게(오전/오후), 발연원 세기를 다르게 해서 다양성 확보하면 더 좋습니다

### 수집 후 라벨 적용 — 시간 기록으로 일괄 라벨링

실험이 끝나면, 기록해둔 시작/종료 시각을 가지고 DB에 라벨을 일괄로 적용합니다. 아래 스크립트를 하나 만들어서 씁니다 (클로드 코드 작업과 무관하게 지금 바로 쓸 수 있습니다):

```python
# server/label_by_time_range.py
"""
기록해둔 실험 시작/종료 시각으로 fire_alarm_log의 label을 일괄 적용한다.
자탐2(광전식구역) 데이터만 대상으로 한다.
"""
import sqlite3
import sys
from datetime import datetime
from pathlib import Path

DB_PATH = Path(__file__).parent.parent / "db" / "bulchimbeon.db"


def label_time_range(start_str: str, end_str: str, label: str, node_id: str = "fire_zone_photoelectric"):
    """
    start_str/end_str 형식: "2026-08-15 14:32:10"
    해당 시간대에 들어온 광전식구역 데이터에 label을 일괄 적용한다.
    """
    start_ts = datetime.strptime(start_str, "%Y-%m-%d %H:%M:%S").timestamp()
    end_ts = datetime.strptime(end_str, "%Y-%m-%d %H:%M:%S").timestamp()

    conn = sqlite3.connect(DB_PATH)
    cur = conn.execute(
        """UPDATE fire_alarm_log SET label = ?
           WHERE node_id = ? AND ts BETWEEN ? AND ?""",
        (label, node_id, start_ts, end_ts),
    )
    conn.commit()
    print(f"{cur.rowcount}개 행에 label='{label}' 적용 완료 ({start_str} ~ {end_str})")
    conn.close()


if __name__ == "__main__":
    # 사용법: python label_by_time_range.py "2026-08-15 14:32:10" "2026-08-15 14:35:00" fire
    if len(sys.argv) != 4:
        print('사용법: python label_by_time_range.py "시작시각" "종료시각" 라벨(fire/cooking/normal)')
        sys.exit(1)
    label_time_range(sys.argv[1], sys.argv[2], sys.argv[3])
```

기록해둔 표를 보고 실험마다 이렇게 실행하면 됩니다:

```bash
python server/label_by_time_range.py "2026-08-15 14:32:10" "2026-08-15 14:35:00" fire
python server/label_by_time_range.py "2026-08-15 14:40:00" "2026-08-15 14:43:00" cooking
python server/label_by_time_range.py "2026-08-15 14:50:00" "2026-08-15 14:53:00" normal
```

**`node_id`는 실제 자탐2 노드 이름으로 맞춰서 바꿔 쓰세요** (ESP32 코드에서 정한 이름 그대로).
