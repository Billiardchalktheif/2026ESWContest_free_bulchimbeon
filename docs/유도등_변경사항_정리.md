# 유도등 엣지 — 실측 반영 변경사항 정리 (팀 전달용)

> 기존 `guides/유도등_실험가이드.md`, `server/evac_light_node.ino`(GitHub 현재 버전) 대비,
> 실물 분해·측정·트러블슈팅 과정에서 확정된 사실과 그에 따른 수정 필요 항목입니다.

---

## 0. 핵심 사실 변경 (모든 수정의 근거)

| 항목 | 기존 문서/코드 가정 | 실측 확정 |
|---|---|---|
| 배터리 구성 | 3셀 직렬 Ni-Cd, 3.6V대 | **AA 사이즈 Ni-Cd 단일셀 1개**(라벨: WB-NC0601, NS-AA600mAh, 공칭 1.2V, 완충 최대 약 1.4V) |
| 배터리 장착 방식 | 커넥터(리드선+2핀 커넥터) | **스프링클립 홀더** (2핀 커넥터는 이 보드 버전에서 미사용 — 보유 중인 예비 Ni-Cd 배터리는 호환 안 됨) |
| 초기 배터리 상태 | — | **심방전 상태**(홀더에서 뺀 채 측정 시 약 30~56mV, 정상 완충전압의 20분의 1 수준) |
| 유도등 강압 방식 | 트랜스(변압기) 기반 정류, DC로 점등 가능 가정 | **캐패시터 강압(용량성 드롭퍼) 회로로 추정** — DC 파워서플라이(PWS-3005U)로는 20V까지 올려도 전류 0mA, 원리적으로 DC 점등 불가 확인 |
| 조도(CDS) 감시 | 포함 (점등 확인용) | **스코프에서 제외** — 이진값이라 회귀예측에 기여 안 함, 육안점검으로도 확인 쉬운 항목 |

## 1. 하드웨어

### 1-1. 전원 투입 방식 변경 (제일 중요)
- **기존 가이드**: 저전압 DC 파워서플라이로 0.5V부터 스윕하며 점등전압 탐색
- **변경**: 이 방식은 원리적으로 불가능함이 확인됨 (캐패시터 강압 회로 추정). **AC220V 정품 플러그 결선 방식으로 전면 변경**
  - 조립식 코드 플러그(나사 고정형) 구매해 백선/흑선 각각 다른 핀에 결선, 적선은 미사용·절연마감
  - 결선 후 통전 전 반드시 멀티미터로 두 핀 사이 저항 측정(실측 기준 약 1.8kΩ 근처 나와야 정상 — 결선 자체 이상 유무 사전 확인)
  - 누전차단기 달린 멀티탭 경유, 최초 통전 시 5~10분 발열/이상징후 관찰 후 방치 가능(상시 감시 불필요)

### 1-2. 배터리 전압 tap 지점 및 방식
- **분압 회로 불필요**: 1.2V 단일셀이 이미 ESP32 ADC 허용범위(0~3.3V) 내이므로, 저항분압(2개) 대신 **보호저항 1개(1kΩ)만 배터리(+) 라인에 직렬**로 넣고 GPIO에 직결
- **tap 방식**: 셀 직접 납땜(리스크 큼, 실제 셀 1개 손상 의심 사례 발생) → 클립 납땜(리지드 클립이라 배터리 삽입/제거 경로 훼손 우려) → **최종적으로 무납땜 방식 채택**: 배터리와 클립 사이에 가는 점퍼선(피복 벗긴 상태)을 끼워 넣고 배터리 삽입 압력으로 고정. 실측상 배터리 삽입에 지장 없음 확인됨
- **주의**: 리지드(비스프링) 클립 구조라 두꺼운 전선이나 다회 납땜 시도는 클립 변형 위험 있음. 반드시 얇은 단선 점퍼선만 사용할 것

### 1-3. 방전시험용 데모 버튼
- 기존 코드는 GPIO13에 버튼(`INPUT_PULLUP` + `FALLING` 인터럽트) 배선을 전제
- **문제 발생**: 특정 버튼에서 "계속 눌린 것으로 인식"되는 현상 확인(다른 프로젝트에서 겪음, 원인 미확정 — 배선 극성/플로팅/디바운스 중 하나로 추정)
- **권장 조치**: 물리 버튼 신뢰성이 확보되기 전까지는 **시리얼 커맨드로 방전시험을 트리거하는 방식**으로 임시 전환 권장 (아래 2-3 참고)

### 1-4. 4대 확장 시 파워서플라이 배선 (시간 남으면)
- 유도등끼리 직결이 아니라, 파워서플라이 출력을 **병렬로 분배**(터미널블록 권장)해서 각 유도등에 개별 공급
- **전류 제한값을 4대 분량으로 상향 조정 필수** (1대 전류 실측값 × 4, 파워서플라이 최대 출력 스펙도 확인)

## 2. 펌웨어 (`server/evac_light_node.ino`)

### 2-1. CDS/멀티플렉서 제거
- `CD74HC4067`, `MUX_SIG_PIN`/`S0~S3`, `selectMuxChannel()`, `readMuxChannelRaw()`, `LUX_MUX_CHANNELS`, `measureApproxLux()`, 패킷의 `lux` 필드 — **전부 삭제**
- 유도등 4개 배터리 전압을 ESP32 ADC1 핀에 **직결** (멀티플렉서 불필요, CDS 제외로 채널 4개면 충분)
  - `VOLTAGE_PINS[4] = {32, 33, 34, 35}` (전부 ADC1, WiFi 사용 중에도 안정 동작)

### 2-2. VOLTAGE_DIVIDER_RATIO 수정
- 기존 `1.5`(3셀 직렬 가정, 실측 전 임시값) → **`1.0`으로 확정** (1.2V 단일셀, 분압 없이 직결 + 보호저항 1개만 직렬)

### 2-3. 방전시험 트리거 방식 추가 검토
- 물리 버튼(GPIO13) 신뢰성 이슈로, **시리얼 커맨드(예: 's' 입력 시 데모모드 시작) 트리거를 병행 지원**하도록 코드 추가 권장
- 버튼 배선이 최종 확정되면 그대로 유지, 안 되면 시리얼 트리거로 대체

### 2-4. ADC 저전압 구간 대응 (배터리 초기 심방전 상태 대응용, 임시)
- ESP32 ADC는 기본 감쇠(11dB, 0~3.3V 풀스케일) 기준 100mV 이하 구간에서 raw=0으로 읽히는 경우가 흔함 (배터리 완전방전 시 30~56mV 구간에서 실제 겪음)
- `analogSetPinAttenuation(pin, ADC_0db)`로 감쇠를 낮춰(풀스케일 약 1.1V) 저전압 구간 분해능을 높이는 임시 모드를 디버그용으로 추가해둠
- **주의**: 배터리가 정상 충전되어 1.2V 근처로 오르면 이 저전압 모드는 오히려 포화(clipping)되므로, 충전 완료 확인되는 대로 **기본 감쇠(11dB)로 복귀 필수**

### 2-5. 헤더 주석 갱신
- "2선식/3선식 전제", "CDS 근사치" 등 더 이상 해당 안 되는 주석 정리
- 배터리 실측 스펙(WB-NC0601, 1.2V) 및 tap 방식(무납땜 압착) 명시

## 3. 서버 / 대시보드

### 3-1. `server/judge/regression.py` — `EVAC_DISCHARGE_THRESHOLD_V` 재확인 필요
- 이 상수가 기존 3.6V대 배터리를 전제로 설정되어 있었다면, **1.2V 단일셀 기준으로 재조정 필요**
- 정확한 값은 실제 방전시험(20분 또는 45초 데모) 때 **LED가 실제로 꺼지는 순간의 전압을 실측해서 확정**해야 함 — 아직 실시되지 않음, 충전 완료 후 최우선 진행 예정

### 3-2. `server/receiver/packet_parser.py` — `lux` 필드 참조 제거
- 현재 `evac_light_log` INSERT 구문에 `pkt.get("lux")`가 남아있음 — CDS 제거에 맞춰 **컬럼/파라미터 정리 필요** (DB 스키마에서 lux 컬럼을 유지할지, NULL 허용으로 둘지는 팀 결정 필요)

### 3-3. 회귀분석 데이터 성격 — 실측 vs 시뮬레이션 이중 트랙 (이미 반영됨, 팀 공유 재확인용)
- `server/judge/regression.py`의 `evaluate_evac_light()`: **실측 데이터** 기반, `demo_mode=0`(평상시)만 사용해 장기 추세 회귀
- `ml/evaluate_predictions.py`: **합성(시뮬레이션) 장기 시계열**로 회귀 알고리즘 자체의 통계적 정확도(MAE)를 사후검증 — 2주 실측만으로는 장기 열화 추세 확보가 불가능하다는 현실적 제약에 대한 대응으로, 이미 이 구조로 설계되어 있음. **추가 작업 불필요, 방향성만 팀 공유**
- 단, **실측 파이프라인(센서→전송→DB저장→방전시험 실증) 자체는 시뮬레이션으로 대체 불가** — 최소한의 실측 데이터 축적과 방전시험 1회 이상 실증은 예선 전 필수

### 3-4. 대시보드 — 조도(lux) 관련 표시 항목 제거
- 대시보드 쪽에서 유도등 상세정보에 조도값을 표시하는 항목이 있었다면 제거 필요 (배터리 전압 추세만 표시)

### 3-5. `docs/개발_체크리스트.md` 반영 필요
- "유도등: 조도센서 1개로 채널 스위칭 테스트", "나머지 채널 배선(조도×4, 저항분압×4)" 항목 — CDS/멀티플렉서 제거에 맞춰 **삭제 또는 "배터리 전압 ADC 직결 ×4"로 수정**
