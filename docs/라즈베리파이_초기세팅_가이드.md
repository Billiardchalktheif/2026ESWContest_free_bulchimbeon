# 라즈베리파이 초기 세팅 가이드 (실물 첫 세팅)

> 리눅스(Raspberry Pi OS) 설치부터, 어제 Windows에서 검증했던 코드를 실물로 옮겨서 다시 확인하는 것까지의 순서입니다.

---

## 0. 목표

1. 라즈베리파이에 OS(리눅스) 설치
2. 원격 접속(SSH) 가능하게 만들기 — 모니터·키보드 없이 컴퓨터에서 제어
3. 어제 Windows에서 검증했던 서버 코드를 그대로 옮겨서, **같은 결과가 실물에서도 나오는지** 확인
4. (오늘은 여기까지) — 실제 ESP32 연동은 하드웨어 조립 끝난 뒤 별도 단계

---

## 1. 준비물

- 라즈베리파이4 본체
- microSD카드 (또는 USB 부팅용 SSD/USB메모리) + 카드리더기
- 전원 어댑터(5V/4A급)
- 컴퓨터(Windows) — SD카드 굽기 및 원격 접속용
- 우리 집/작업 공간 WiFi 이름과 비밀번호
- (선택) 초기 문제 생겼을 때 대비용 모니터+키보드+마우스, HDMI 케이블

---

## 2. OS 설치 — Raspberry Pi Imager

### 2-1. 프로그램 설치
컴퓨터에서 https://www.raspberrypi.com/software/ 접속 → **Raspberry Pi Imager** 다운로드·설치

### 2-2. SD카드(또는 USB) 준비
카드리더기에 SD카드 꽂기 → 컴퓨터가 인식하는지 확인

### 2-3. Imager 실행 및 설정
1. **"CHOOSE DEVICE"** → Raspberry Pi 4 선택
2. **"CHOOSE OS"** → Raspberry Pi OS (other) → **Raspberry Pi OS Lite (64-bit)** 선택
   - ⚠️ Desktop 버전 말고 **Lite** — 화면 없이 서버만 상시 구동할 거라 이게 맞음
3. **"CHOOSE STORAGE"** → 꽂아둔 SD카드 선택
4. **⚙️ (톱니바퀴, 우측 하단 설정 아이콘) 클릭** → 아주 중요한 단계, 여기서 미리 설정해두면 모니터 연결 없이 바로 원격 접속 가능:
   - **Set hostname**: `bulchimbeon.local` (또는 원하는 이름)
   - **Enable SSH** 체크 → "Use password authentication" 선택
   - **Set username and password**: 아이디/비밀번호 설정 (기억해두기)
   - **Configure wireless LAN**: 우리 WiFi 이름/비밀번호 입력
   - **Set locale settings**: 국가 South Korea, 시간대 Asia/Seoul
5. 저장 → **"WRITE"** 클릭 → SD카드에 OS 굽기 시작 (몇 분 소요)

### 2-4. 부팅
완료되면 SD카드를 라즈베리파이에 꽂고 전원 연결 → 자동으로 부팅되며 설정해둔 WiFi에 자동 접속됨 (1~2분 소요)

---

## 3. 원격 접속 (SSH)

컴퓨터에서 명령 프롬프트(또는 PowerShell) 열고:

```
ssh 아이디@bulchimbeon.local
```

(hostname으로 안 잡히면, 공유기 관리 페이지에서 IP 확인 후 `ssh 아이디@192.168.0.xx` 형태로 시도)

처음 접속하면 "계속 연결하시겠습니까?" 같은 문구가 뜨는데 `yes` 입력. 그다음 아까 설정한 비밀번호 입력하면 접속 완료 — 검은 터미널 화면이 뜨면 성공.

**⚠️ IP 주소는 메모해두기** — 이게 나중에 앱 설정 화면, 다른 ESP32 노드들이 접속할 주소가 됨. 가능하면 공유기 설정에서 **이 라즈베리파이에 고정 IP를 할당**해두면(DHCP 예약), 재부팅해도 주소가 안 바뀌어서 편함.

## 4. 시스템 업데이트 (최초 1회)

```bash
sudo apt update
sudo apt upgrade -y
```
몇 분 걸릴 수 있음, 완료될 때까지 대기.

## 5. 코드 가져오기

```bash

cd 2026ESWContest_free_bulchimbeon/server
```

(레포가 Private면 접속 안 될 수 있음 — Public 상태 유지 필요, 또는 접속 안 되면 알려주기)

## 6. 파이썬 패키지 설치

```bash
pip install -r requirements.txt --break-system-packages
```

`requirements.txt`가 없으면, 아까 검증 때 쓴 패키지들을 직접:
```bash
pip install flask scikit-learn numpy joblib --break-system-packages
```

⚠️ 라즈베리파이 OS 최신 버전은 시스템 파이썬을 보호하려고 `--break-system-packages` 옵션 없이는 설치가 막힐 수 있음 — 에러 뜨면 이 옵션 붙이면 됨.

## 7. 어제 검증했던 것 그대로 재현

```bash
python3 main.py
```
(다른 터미널 창 하나 더 열어서 SSH로 다시 접속한 뒤)
```bash
cd 2026ESWContest_free_bulchimbeon/server
python3 simulate/dummy_generator.py --all
```

**어제 Windows에서 나왔던 것과 같은 로그(정상/주의/경보 판정, MAE 수치 등)가 라즈베리파이에서도 그대로 나오는지 확인.** 이게 되면 "코드 이식 성공" — 오늘 목표 달성.

## 8. 오늘은 여기까지 — 다음 단계 (참고용)

- 하드웨어(자탐/수계/가스계/소화기/유도등) 조립이 끝나면, 각 ESP32가 **이 라즈베리파이의 IP 주소로 UDP 전송**하도록 코드의 `SERVER_IP` 값을 실제 주소로 맞춰야 함
- 대시보드(`dashboard/app.py`)와 API(`dispatch/api.py`)도 라즈베리파이에서 실행해두면, 다른 기기(앱, 브라우저)에서 `http://[라즈베리파이IP]:포트`로 접속 가능해짐
- 앱 설정 화면의 "서버 IP 주소" 입력란에도 이 IP를 넣으면 연동 준비 완료
