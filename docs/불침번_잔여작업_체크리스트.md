## 1단계 — 하드웨어 최종 마무리 + 동작확인

각 엣지가 "얼추 완성"에서 "완전 완성"으로 넘어가는 단계입니다. `guides/실험_캘리브레이션_데이터축적_통합정리.md`의 **Part 1(캘리브레이션/동작확인)**을 엣지별로 전부 체크합니다.

- [ ] **가스계**: 영점·스케일·공병중량 캘리브레이션, 10% 임계치 전환 동작확인
- [ ] **소화기**: 4개 리프노드 정지상태 기준값 캘리브레이션, 이벤트 임계값 설정, ESP-NOW 페어링 확인
- [ ] **수계**: INA219 2채널 정상구분, 압력센서 분압 확인, **체절 vs 부하 전류 실측(최우선, 방향 확정)**
- [ ] **유도등**: 적정 구동전압 실측, 배터리 자동전환 검증, 저항분압+CDS 정상표시 확인
- [ ] **자탐1/2**: ADS1115+센서 정상값 확인, MQ-2 예열 후 안정화 확인

**모든 캘리브레이션이 끝나야 다음 단계(데이터 축적)의 값이 신뢰할 수 있습니다 — 순서 건너뛰지 않기.**

---

## 2단계 — 데이터 축적

`guides/실험_캘리브레이션_데이터축적_통합정리.md`의 **Part 2·3·4** 참고.

- [ ] **자탐2**: fire/cooking/normal 각 15~20회, 시간 기록 → `label_by_time_range.py`로 일괄 라벨링
- [ ] **수계**: 체절/부하 각 30~50회(자동 라벨), 공회전 별도 시나리오
- [ ] **가스계**: 손실률 추세 로깅 (지속)
- [ ] **유도등**: 전압 방전 추세 로깅 (완성 즉시 백그라운드로 계속)
- [ ] **자탐1**: 열원반응 재현성 10회 이상
- [ ] **소화기**: 오탐/이탈 시나리오 각 5~10회 반복 검증

---

## 3단계 — AI 모델 학습 실행 + 회귀분석 적용

데이터가 30개 이상 모이는 대로 바로 실행 가능 (이미 검증된 스크립트, 추가 코드 작업 불필요).

- [ ] `ml/train_pump_classifier.py` 실행 (수계 펌프 파형 분류)
- [ ] `ml/train_nuisance_classifier.py` 실행 (자탐2 비화재보 판별)
- [ ] 회귀분석 함수 적용 확인: 자탐 배선추세, 유도등 배터리추세, 가스계 10% 예측
- [ ] 학습된 모델을 서버 판정엔진에 실제로 연결해 결과 확인 (더미값이 아니라 실측 데이터 기준으로)

---

## 4단계 — 전체 시스템 통합

개별 엣지가 다 되어도, 5개가 동시에 붙었을 때 문제가 생기는 경우가 많아 반드시 별도 확인이 필요합니다.

- [ ] 판정엔진(rules/regression/ai_models) 통합 확인
- [ ] 대시보드 API 완성 + 친구 대시보드와 연동 테스트
- [ ] LCD(I2C) 라즈베리파이 직결, 상태 순환표시 확인
- [ ] 부저 경보 패턴, 이벤트 로그 팝업 연동 확인
- [ ] **전체 5개 모듈 동시 가동 통합 테스트** (라즈베리파이 하나로 5개 엣지 데이터 동시 수신·판정)
- [ ] 통합 테스트 중 발견된 문제 리스트업 → 버그 수정
- [ ] 케이스/마운팅 마무리 (3D프린팅 등 외관 정리)
- [ ] 시연 시나리오 리허설 (실제 발표처럼 처음부터 끝까지)

## 우선순위 메모

1. **1단계(캘리브레이션)를 먼저 다 끝내기** — 여기 값이 틀리면 2·3단계 데이터가 전부 무의미해집니다.
2. **2단계는 엣지별로 팀원과 병행 가능** — 특히 자탐2·수계는 반복 횟수가 많아 가장 먼저 시작.
3. **3단계(학습 실행)는 스크립트만 돌리면 되니 시간이 오래 안 걸립니다** — 데이터만 충분히 쌓이면 바로 처리.
4. **4단계(통합 테스트)는 절대 마감 직전에 몰아서 하지 않기** — 개별로는 잘 되던 것도 동시 가동하면 전원/네트워크 문제가 새로 생길 수 있습니다. 최소 마감 며칠 전에는 한 번 붙여봐야 합니다.
5. **5단계(제출물)는 4단계와 병행 준비 가능** — 보고서 초안과 영상 스토리보드는 통합 테스트 완료를 기다리지 않고 미리 써둘 수 있습니다.
