# 불침번 — 텔레그램 알림봇 + PWA 통합 가이드

두 기능 다 기존 코드를 갈아엎지 않고 **파일 추가 + 몇 줄 연결**로 끝나요.

---

## 1. 텔레그램 알림봇 연결하기

### 파일 위치
`telegram_alert.py` → `server/telegram_alert.py`로 이동

### 사전 준비 (팀 채팅방 기준, 5분)
1. 텔레그램에서 `@BotFather` 검색 → `/newbot` → 이름 정하기 → 토큰 발급
2. 만든 봇을 팀 단체방에 초대
3. 봇한테 아무 메시지나 한 번 보내기 (chat_id 확인용)
4. 브라우저로 `https://api.telegram.org/bot<TOKEN>/getUpdates` 열어서 응답 안에 있는 `"chat":{"id": 숫자}` 찾기
5. 라즈베리파이에서 환경변수로 등록 (터미널에서):
   ```bash
   export BULCHIMBEON_TG_TOKEN="발급받은_토큰"
   export BULCHIMBEON_TG_CHAT_ID="확인한_chat_id"
   ```
   (매번 새로 켤 때마다 치기 귀찮으면 `~/.bashrc` 맨 아래에 두 줄 추가해두면 자동 적용)

### 코드 연결
`server/alert_output.py` 맨 위에 한 줄 추가:
```python
from telegram_alert import send_telegram_alert
```

경보 발생시키는 함수 안에 한 줄 추가:
```python
def raise_alert(zone, message, severity="warning"):
    buzzer_on()
    led_on(zone)
    send_email(zone, message)
    send_telegram_alert(zone, message, severity)  # ← 이 줄 추가
```

### 테스트
```bash
python server/telegram_alert.py
```
"전송 성공"이 뜨고 텔레그램방에 테스트 메시지가 오면 끝.

## 2. PWA(홈화면 앱처럼) 연결하기

### 파일 위치
- `manifest.json` → `dashboard/static/manifest.json`
- `service-worker.js` → `dashboard/static/service-worker.js`

### 아이콘 준비 (직접 만들어야 하는 유일한 부분)
192x192, 512x512 크기의 PNG 아이콘 2개를 만들어서
`dashboard/static/icons/icon-192.png`, `icon-512.png`로 저장하세요.
(로고 없으면 일단 불 이모지(🔥)나 팀 로고 텍스트만 넣은 정사각형 이미지로 시작해도 됩니다 — 나중에 교체 가능)

### 대시보드 HTML에 연결
`dashboard/templates/index.html`(또는 메인 템플릿)의 `<head>` 안에 추가:
```html
<link rel="manifest" href="/static/manifest.json">
<meta name="theme-color" content="#d32f2f">
```

`</body>` 직전, 또는 메인 JS 파일 안에 추가:
```html
<script>
  if ("serviceWorker" in navigator) {
    navigator.serviceWorker.register("/static/service-worker.js");
  }
</script>
```

### 확인 방법
1. 라즈베리파이 서버 켜고 스마트폰으로 대시보드 접속 (크롬/사파리)
2. 브라우저 메뉴에서 "홈 화면에 추가" 또는 "앱 설치" 버튼이 뜨는지 확인
3. 추가하면 홈 화면에 아이콘 생기고, 탭하면 주소창 없이 앱처럼 전체화면 실행됨

**참고**: PWA 설치 버튼은 `https://`(보안 연결)에서만 뜨는 게 원칙이지만, 같은 와이파이 내부(`http://라즈베리파이_IP`)에서는 예외로 허용되는 경우가 많아서 로컬 테스트는 대부분 그냥 됩니다. 문제 생기면 알려주세요.
