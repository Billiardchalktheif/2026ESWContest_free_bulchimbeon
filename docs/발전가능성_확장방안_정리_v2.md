# 개발 결과물의 발전 가능성 — 시제품 → 실물 확장 방안

> 발표자료 6번 항목(파급력 및 기대효과 / 발전 가능성)용 소재입니다.

---

## 1. 통신 인프라 확장

현재 PoC는 축소 규모(단일 공간, 짧은 배선)를 전제로 WiFi/UDP와 근거리 무선(ESP-NOW)을 사용했으나, 실물 복합건축물 규모로 확장 시 다음과 같은 전환이 가능합니다.

| 구분 | 현재 (PoC) | 실물 확장 시 |
|---|---|---|
| 유선 구간 (자탐·수계·가스계·유도등) | 짧은 점퍼선, 동일 공간 내 배선 | **RS-485 통신**으로 전환 — 최대 1.2km 장거리, 노이즈 강건성, 다수 노드를 하나의 버스에 데이지체인 연결 가능 |
| 무선 구간 (소화기) | 단일 게이트웨이 | **층/구역별 게이트웨이 다중 배치**로 무선 커버리지 확장 — 이미 "구역당 게이트웨이 1개" 구조로 설계돼 있어 개수만 늘리면 됨 |
| 중앙 서버 | 라즈베리파이 단일 대수 | RS-485 마스터 역할 + 다중 무선 게이트웨이 취합 지점으로 확장, 서버 이중화(冗長化)도 고려 가능 |

**핵심 포인트**: 통신 방식 전환은 센서·판정 로직 자체를 재설계할 필요 없이 **물리 계층(전송 매체)만 교체**하면 되는 구조로 설계했습니다. 즉 지금 검증한 알고리즘(사각지대 감지 로직)은 실물 규모에서도 그대로 재사용됩니다.

## 2. 설비별 실물 확장 방안

### 자탐
- 현재: 미니어처 챔버 내 감지기 모형 2개씩(차동식/광전식)으로 루프 시뮬레이션
- 확장: 실제 수신기 단자함에서 **회로 단위로 유선 tap** — 감지기 개별이 아닌 방호구역 회로 단위로 노드를 배치해 개수 대비 원가 증가를 방지

### 수계
- 현재: 미니 워터펌프 + 니들밸브(수동) 기반 축소 배관
- 확장: 실제 펌프실 배관에 INA219(전류)·압력센서 설치, 니들밸브는 **솔레노이드밸브(PWM 제어)**로 전환해 성능시험 완전 자동화

### 가스계 소화설비 (CO2 소화설비)
- 현재: 소형 평판 로드셀 2개 병렬, 판정 임계치 중량손실 10% (출처: 소방시설등 점검관리 매뉴얼)
- 확장: 실물 저장용기(68L급) 규모에 맞는 **압축형(캐니스터) 로드셀**로 전환 — 대형 하중에 적합한 구조로 재설계

### 소화기
- 현재: 리프노드 4개(그중 1개만 실물 부착)
- 확장: 리프노드는 별도 설계 변경 없이 **개수만 확장**(건물 내 소화기 전수 배치) — 이미 저전력 무선 구조라 원가 증가율이 완만함

### 유도등
- 현재: 멀티플렉서(CD74HC4067) 1개로 4개 처리
- 확장: 멀티플렉서 추가 배치 또는 캐스케이드 연결로 **동일 구조를 그대로 스케일업** — 채널 확장 여유(16채널 중 8채널만 사용 중)를 이미 확보해둔 상태

## 2-1. 매뉴얼 원문 재검토로 발견한 추가 사각지대 (확장 로드맵)

소방시설등 점검관리 매뉴얼의 설비별 점검표(자탐/수계/가스계/소화기/유도등 전체)를 항목 단위로 재검토한 결과, 현재 스코프에서 다루지 않는 사각지대 중 **기존 설계를 그대로 재사용해 확장 가능한 지점**을 확인했습니다.

**자탐 수신기·수계 감시제어반의 예비전원(축전지) 열화 감시**
점검표상 각각 "예비전원 성능 적정 및 상용전원 차단 시 예비전원 자동전환 여부"(자탐 15-H-002), "예비전원 확보 유무 및 시험 적합 여부"(수계 3-K-017) 항목이 존재합니다. 현재 시스템은 유도등 배터리 열화만 감시하고 있으나, **이미 검증한 유도등 배터리 전압 추세 감시 로직(회귀분석 기반 예측)을 동일하게 적용**하면, 별도 설계 없이 자탐 수신기·수계 감시제어반의 예비전원까지 감시 범위를 확장할 수 있습니다. 즉 알고리즘 재사용만으로 새로운 사각지대를 메우는 사례입니다.

*(참고: 수원 유효수량(수계 3-A-001/002) 항목도 검토했으나, 실제 현장에서는 이미 급수경보장치가 저수위를 자동 감지·보충하는 구조라 별도 상시감시의 실익이 낮다고 판단해 확장 후보에서 제외했습니다.)*

## 3. AI/분석 고도화 방향

- 현재 AI 필수 구간은 수계(또는 전환된 펌프성능시험 로직)에 한정 — 데이터가 축적되면 다음 확장 가능:
  - **예측 정비 고도화**: 단순 선형 추세(회귀)에서 벗어나, 여러 설비의 열화 패턴을 동시에 학습해 상호 연관성(예: 특정 계절·습도와 배선 열화 속도의 상관관계) 분석
  - **이상 탐지 확장**: 자탐 루프 저항, 유도등 배터리 등 현재 통계 기반(z-score)으로 처리 중인 항목도 데이터 축적 후 이상탐지 모델로 고도화 가능
  - **건물 단위 통합 대시보드**: 여러 건물의 데이터를 취합해 설비 유형별 평균 수명, 고장 예측 정확도를 지속 개선

---

## 4. 활용성·시장성

- **소방시설관리사 업무 보조 도구**: 점검 데이터 자동 축적으로 관리사의 점검 효율화 및 근거자료 제공
- **지자체 스마트 소방 인프라와의 연계 가능성**: 현재 지자체 시스템(서울시 등)이 신호 원격화 수준에 머물러 있는 것과 달리, 설비별 정량 열화 진단이라는 차별화된 데이터를 제공할 수 있어 상호 보완적 연계가 가능
- **기술 검증기관 활용**: 축적된 열화 패턴 데이터는 한국소방산업기술원(KFI) 등 기술 검증 기관의 성능 기준 개선 연구에도 참고자료로 활용 가능

## 5. 확장 로드맵 요약 (한 장 요약용)

```
[현재 PoC]                          [1차 확장 — 결선]                [2차 확장 — 실물]
축소 미니어처                        자동화 강화                       실물 건물 배포
├ 짧은 유선/근거리 무선         →    ├ 솔레노이드밸브 자동화      →    ├ RS-485 장거리 유선
├ 단일 게이트웨이                    ├ 데이터 축적 시작                 ├ 다중 게이트웨이
└ 수동 조작 시연 요소                └ AI 모델 정교화                   └ 실물 규격 부품 전환
```
