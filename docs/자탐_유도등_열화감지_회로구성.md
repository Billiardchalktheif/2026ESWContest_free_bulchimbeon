# 자탐 루프저항 열화 + 유도등 배터리 열화 — 회로 구성 상세

> 센서 자체(온도센서, 전압분압) 말고, "열화를 어떻게 물리적으로 재현하고 감지하는가"만 집중해서 정리했습니다.

---

## 1. 자탐 — 루프저항 열화 감지 회로

### 1-1. 우리가 뭘 흉내내려는 건지 (원리 복습)

실제 자탐 배선은 수신기↔감지기 사이 수백 미터 전선인데, 시간이 지나며 **부식·접촉불량**으로 이 배선의 저항이 서서히 올라갑니다. 우리는 이걸 **"짧은 전선 + 일부러 헐겁게 만들 수 있는 연결부"**로 축소 재현합니다.

### ⚠️ 먼저 확인할 것 — 공급전압

이전에 "실제 DC 24V 배선공사는 불가능하니 저전압(3.3V/5V)으로 시뮬레이션한다"고 정리했었는데, 서버 코드(`fire_alarm_differential_node.ino`)에 `SUPPLY_VOLTAGE = 24.0`이라는 상수가 있었습니다. **이건 실제로 24V 전원을 쓰라는 뜻이 아니라, 코드 작성 시점에 "실측 후 재조정"하라고 남겨둔 기본값(placeholder)일 가능성이 높습니다.**

**아래는 5V 기준으로 설계했습니다** (ESP32 자체 5V 핀으로 공급 가능, 안전하고 계산도 간단함). 이 값으로 진행할 거면, 코드의 `SUPPLY_VOLTAGE` 상수도 `5.0`으로 맞춰서 고쳐야 합니다 — 이 부분 팀원과 확인 후 진행하세요.

### 1-2. 회로 구성 (직렬 루프 + 션트저항 방식)

```
ESP32 5V ──[R_loop 200Ω]──[열화 시뮬레이션 지점]──[R_shunt 100Ω]── GND
                                                        │
                                              이 지점 전압을 ADS1115로 측정
```

**부품 3개만 있으면 됩니다:**

| 부품 | 역할 | 값 |
|---|---|---|
| **R_loop (고정저항)** | 정상 배선을 흉내내는 기준 저항 | 200Ω (자탐용 저항세트에서 사용) |
| **열화 시뮬레이션 지점** | 나사식 터미널블럭 2개를 살짝 헐겁게/타이트하게 조절 가능하게 연결 | 저항값 0~50Ω 정도로 변함 (나사 조임 정도에 따라) |
| **R_shunt (고정저항)** | 전류 측정용 | 100Ω |

### 1-3. 왜 이 값들인지 (계산)

```
전체 저항 = R_loop(200) + 열화저항(0~50) + R_shunt(100) = 300~350Ω
전류 = 5V ÷ 300~350Ω ≈ 14.3~16.7mA  (안전한 저전류 범위)
R_shunt에 걸리는 전압 = 전류 × 100Ω ≈ 1.43~1.67V  (ADS1115가 안전하게 읽을 수 있는 범위)
```

**이 정도 저항 변화(0→50Ω)로도 전압이 약 240mV나 바뀌기 때문에**, 미세한 접촉불량 변화도 충분히 감지할 수 있는 민감도입니다.

### 1-4. 열화 시뮬레이션 지점 — 물리적으로 어떻게 만드는지

**방법**: 나사식 터미널블럭 하나를 배선 중간에 넣고, **나사를 조이는 정도로 접촉저항을 인위적으로 조절**합니다.
- 나사를 꽉 조이면 → 접촉저항 거의 0 → "정상 배선" 상태
- 나사를 살짝 풀면 → 접촉저항 증가 → "부식/접촉불량 진행 중" 상태 재현

시연할 때 이 나사를 카메라 앞에서 살짝 돌리면서 "지금 배선 상태가 나빠지는 것을 재현합니다"라고 보여주면 좋은 시연 포인트가 됩니다.

### 1-5. ADS1115 연결

```
ADS1115 채널 A1 → [R_loop와 열화지점 사이] 또는 [열화지점과 R_shunt 사이] 접점에 연결
```
정확히는 **R_shunt 양단 전압**을 측정해야 하므로, R_shunt 위쪽(열화지점과 만나는 지점)과 GND 사이 전압을 ADS1115로 읽습니다.

### 1-6. 코드에서 저항값 역산

```cpp
const float SUPPLY_VOLTAGE = 5.0;   // 24.0 → 5.0으로 수정 필요
const float SHUNT_OHM = 100.0;      // 10.0 → 100.0으로 수정 필요

float vShunt = ads.readADC_SingleEnded(1) * (ADS_LSB_VOLTAGE);  // 실제 코드의 ADS1115 읽기 방식대로
float current = vShunt / SHUNT_OHM;
float loopResistance = (SUPPLY_VOLTAGE - vShunt) / current;
// loopResistance ≈ 200 + 열화저항(0~50) 로 계산됨
```

**팀원한테 전달할 것**: `SUPPLY_VOLTAGE`와 `SHUNT_OHM` 상수를 실제 회로값(5V, 100Ω)에 맞춰 수정해야 합니다.

## 2. 유도등 — 배터리 열화 감지 회로

### 2-1. 원리 복습

유도등 내장 배터리(Ni-Cd, 3.6V 근처)가 서서히 방전되며 전압이 떨어지는 걸 추적합니다. **원래 회로를 끊지 않고, 배터리 단자에 병렬로 살짝 걸쳐서(tap) 전압만 엿보는 방식**입니다.

### 2-2. 회로 구성

```
유도등 배터리(+) ──┬── (원래 유도등 회로로 그대로 연결, 손대지 않음)
                    │
                   R1 (10kΩ)
                    │
                    ├── 이 지점 전압을 ESP32 ADC(또는 ADS1115)로 측정
                    │
                   R2 (10kΩ)
                    │
유도등 배터리(-) ──┴── GND 공통
```

### 2-3. 왜 저항분압이 필요한지, 왜 이 값인지

Ni-Cd 배터리는 완충 시 최대 **4V 안팎**까지 나올 수 있는데, ESP32 ADC는 3.3V가 한계입니다. **R1=R2=10kΩ로 정확히 절반**으로 낮추면:

```
배터리 4V일 때 → ADC가 보는 값 = 2V (안전)
배터리 3.0V(방전)일 때 → ADC가 보는 값 = 1.5V
```

코드에서는 **읽은 값 × 2**로 원래 배터리 전압을 역산합니다.

### 2-4. 실제 연결 지점 — 어디서 따오는지

지난번 확인한 유도등 메인보드 사진 기준으로, **메인보드↔배터리 사이 커넥터의 빨강(+)/검정(-) 전선에 점퍼선을 병렬로 덧대서** 분압 회로로 연결하면 됩니다. 유도등 자체 동작(충전, 점등)에는 전혀 영향 없습니다 — 전류를 거의 안 끌어가는 전압 측정용 병렬 연결이기 때문입니다.

### 2-5. 코드

```cpp
const float VOLTAGE_DIVIDER_RATIO = 2.0;  // R1=R2 동일값이므로 정확히 2배

float measureBatteryVoltage() {
  float adcVoltage = ads.readADC_SingleEnded(0) * ADS_LSB_VOLTAGE;  // 분압 후 전압
  return adcVoltage * VOLTAGE_DIVIDER_RATIO;  // 원래 배터리 전압으로 환산
}
```

## 3. 두 회로 공통 — 열화를 "빠르게" 관찰하려면

실제로는 몇 달에 걸쳐 일어나는 변화를 시연 시간 안에 보여줘야 하니:

- **자탐**: 나사를 시연 중 직접 손으로 조였다 풀었다 — 순간적으로 재현 가능 (기다릴 필요 없음)
- **유도등**: 배터리를 실제로 방전시켜야 하므로 시간이 걸림 — 이미 만들어둔 **데모모드(45초 압축 방전시험)**를 그대로 활용하면 됨
